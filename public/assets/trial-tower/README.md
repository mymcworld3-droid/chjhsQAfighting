# 試煉之塔角色立繪

取材自最白的烏鴉《誰讓他修仙的！》。所有立繪均為新製作的二次創作詮釋，並非官方設定圖。使用內建 image_gen 分別生成，保留透明背景；WebP 為相同作品的網頁編碼，縮圖僅作等比例縮小。各圖完整提示詞見 prompts.json。

樓層境界代表試煉投影的強度，不代表原著角色的實際修為。玩家自身境界系統不受本塔移除煉虛期的變更影響。

## 逐層輪替

25 位角色，各章使用十名對手逐層輪替。同一個十層區段不重複角色；任意相鄰五層也都使用不同角色和立繪，跨章交界同樣不重複。100 層固定為幕後黑手。

| 樓層 | 塔內境界（每十層） | 逐層輪替的十位對手 |
| --- | --- | --- |
| 1–20 | 煉氣期、築基期 | 虎妖、秦元浩、楚舵主、唐雲生、不朽教教主、劉副教主、高正來、段清水、莫笑愁、楊崆峒 |
| 21–40 | 金丹期、元嬰期 | 劉副教主、高正來、段清水、莫笑愁、楊崆峒、武有道、巫祭尊者、虛空至尊、夢魘至尊、萬法道君 |
| 41–60 | 化神期、合體期 | 武有道、巫祭尊者、虛空至尊、夢魘至尊、萬法道君、司辰神君、司雷神君、關山海、司命、中天帝君 |
| 61–80 | 大乘期、半仙 | 司辰神君、司雷神君、關山海、司命、中天帝君、武堯、左史仙、應天屍、寂滅仙、幕後黑手 |
| 81–100 | 真仙、超脫 | 司辰神君、司雷神君、關山海、司命、中天帝君、武堯、左史仙、應天屍、寂滅仙、幕後黑手 |

每層數值仍使用原塔的連續成長曲線；只以二十層分組安排角色名單，並非二十層共用一名對手。預覽、開戰、下一層共用 cultivation/trial-tower-guards.js。角色採用曾與主角一方敵對或涉案時期的試煉投影，後續立場改變不影響投影名單。
