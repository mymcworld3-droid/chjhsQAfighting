# 大地圖玩家角色素材 v1

保留現有男女主角：黑髮束髮、白衣、青灰衣襟、玉佩；女主保留佩劍。以使用者提供的地圖角色圖作為 Q 版風格參考，沒有套用參考角色的白髮與法杖。

## 規格

- 每套 448 × 448 透明圖集，4 欄 × 4 列；每格 112 × 112。
- 由上往下為 down、right、left、up；左右方向已依實際生成結果核對。
- 第 0 欄為待機，行走欄序為 1、2、3、0，每格 130 ms，一循環 520 ms。
- 使用經過時間計算影格：`frames[Math.floor(elapsedMs / 130) % 4]`，不可依畫面幀數累加。
- 建議地格 40 CSS px，角色圖框 56 × 56 CSS px，實際角色約高 48 px。
- 腳底錨點為來源格 (56,104)，顯示時為 (28,52)。角色身體向格子上方延伸，腳底固定於站立點。
- 以腳底 y 座標排列遮擋；碰撞位置只占一個地格，衣袖與飄帶不算碰撞。
- 移動停下後切回該方向第 0 欄。走路只在角色位置移動時播放。
- WebP 為正式載入版本，PNG 為相容備援；`manifest.json` 提供尺寸、錨點與播放資料。

## 檔案

- `player-male.webp` / `player-female.webp`：正式四方向圖集。
- `player-male.png` / `player-female.png`：透明 PNG 備援。
- `player-*-idle.png`：朝下待機單張。
- `preview.html`：可獨立開啟的待機／行走檢視頁，沒有接入遊戲流程。
- `source/`：原始生成圖集與完整提示詞；原圖不加入預載。
- `docs/design/world-map-players/walk-preview.gif`：實際建議大小的動態預覽。

以內建圖片生成工具製作。打包可執行 `python scripts/pack-world-map-players.py`，需 Pillow、NumPy、SciPy。只進行切格、雜點清理、等比例縮放與腳底對齊，保留生成圖的 alpha。

目前為第一版美術素材；正式接入地圖後仍需觀察連續行走的衣襬、步態與實際背景對比。此次沒有新增地圖玩法或調整原有角色立繪。
