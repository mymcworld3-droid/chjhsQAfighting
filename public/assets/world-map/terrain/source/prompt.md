Use case: stylized-concept. Asset type: seamless repeatable terrain texture for a top-down mobile Chinese cultivation RPG grid world.
Create ONE square seamless tile of ordinary green lawn, viewed strictly vertically from above (orthographic). This is the basic walkable grass ground beneath small chibi characters. Quiet muted medium moss / jade green palette, soft hand-painted 2D anime RPG look, understated tiny short grass blade clusters sparsely scattered, fine subtle mottled ground texture. Mostly calm flat green with gentle irregular variation, low contrast so white-robed chibi characters and grid overlays remain readable at a 40-pixel map cell. No dramatic lighting, no vignette, no central subject. Uniform density and brightness everywhere. Entire image is continuous grass to every edge. Opposite edges must match perfectly for seamless horizontal and vertical repetition. Small-scale texture, not a patch floating in space. No stones, flowers, trees, paths, dirt holes, borders, checkerboards, baked-in grid lines, shadows, text or watermarks. Opaque background. Produce only terrain texture, no UI and no characters.
