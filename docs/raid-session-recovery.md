# 團本答題恢復

- 一般團本請求在 20 秒內結束等待，出題請求上限 90 秒；逾時涵蓋登入憑證、網路及讀取回應。失敗不會自動重送建立隊伍或消耗入場券的操作。
- 每道題目保存簽發時的出手序號。房間推送先更新答題數、HTTP 回覆卻遺失時，仍沿用原題號、原答案重試；若房間已提供同題結算，直接顯示解析。
- 已完成的答案可在勝利或玩家倒下後取回同一筆結算，不再造成傷害或增加答題數。票證仍驗證玩家、房間、題目與序號。
- 等待下一題時只允許一次切換；離隊、換場或戰敗後，晚到的出題不能重新打開答題畫面。過期票證會回到戰場，允許重新取題。
- 動畫佇列在渲染或音效失敗時也會釋放。答題紀錄與統計失敗不會中斷戰鬥；心跳請求尚未完成時不再疊加。

回歸測試涵蓋 40 題連續結算、推送先於 HTTP、回覆遺失、連點、動畫音效失敗、逾時、勝負後重試及三個客戶端的真實 HTTP 串流。這些測試不代表已在玩家的平板或正式帳號重現所有故障。
