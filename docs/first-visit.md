# 首次免註冊修行

同一瀏覽器首次未登入時，先顯示兩位主角的歡迎畫面。玩家按「免註冊，開始答題」後使用 Firebase 匿名身分，不需要先填年級、強弱項或註冊。既有玩家可從歡迎畫面直接 Google 登入。

流程為：歡迎 → 正式研修所選範圍（年級／科目／章節）→ 白板與問道助手簡介 → 正式問道答題 → 首題答對且保存成功 → 加強的煉氣一層突破 → 邀請綁定／登入 → 五張世界背景介紹 → 選擇性別與道號 → 宗門。

- 範圍會以正式 `gameSettings.focusedUnits` 保存；新手視圖先隱藏分享、匯入、出題模式及自訂範圍，完成後恢復完整研修所。
- 答錯與放棄可繼續；首題答對依原問道規則取得 1 修為與 20 靈石。保存成功前不播放首次突破、不允許進入下一題；保存失敗提供重試，`arrivalTrialAnswerV1` 保證首題重试／多分頁不重複領取。首次答題期間不觸發隨機機緣。
- 重新整理可續接範圍、題目或綁定邀請；儲存已成功但邀請尚未顯示，也直接回到邀請。Google 視窗取消時保留匿名身分及成果。
- 新帳號使用 `linkWithPopup` 綁定，保留匿名 UID 與所有成果。若 Google 憑證屬於既有帳號，改登入該帳號，保留它的角色、裝備、修為及餘額；不以匿名資料覆蓋既有玩家。
- 已有性別的帳號在世界介紹後直接回宗門；新角色保存性別／道號後回宗門。序章改由第一項仙道任務手動開啟。
- 年級、強項、弱項為洞府的選填資料；登入不再出現問卷。
- 載具狀態記在 `qingyun:first-visit:v1`，完成後登出不再重播首次試答；清除網站資料或改用其他瀏覽器視為新的載具環境。帳號完成旗標為 `users/{uid}.arrivalOnboardingV1`。
- `?qa=1` 的舊匿名測試入口仍保留，跳過正式首次流程。

檢查：`node --test tests/first-visit.test.cjs tests/cultivation.test.cjs tests/story-first-login.test.cjs`；靜態資源更新後執行 `npm run build:module-versions`。
