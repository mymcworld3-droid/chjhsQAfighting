# 仙盟聊天室與範圍分享

- 仙盟提供「好友」「聊天室」「範圍分享」「班級」四個獨立分頁。
- 聊天室顯示一般訊息與洞天邀請；`curriculum-share` 卡片只在範圍分享顯示，最新分享排在最上方。
- 修習清單的發布按鈕改為「發布至範圍分享」。原有分享碼、複製、匯入與「查看並加入清單」保留；分享分頁也提供開啟個人範圍清單的入口。
- 舊分享資料保留在既有 `global_chat` 中，依訊息類型分流，不需要搬移或刪除資料，也不新增資料庫權限或複合索引。
- 兩個分頁各自補足最近 25 則資料；即使最新訊息全來自另一分頁，仍會向較早紀錄分頁讀取。只監聽目前開啟的公開清單；未讀提示各自追蹤最新一則，讀取其中一個分頁不會清除另一個分頁或好友私訊的提示。
- 已讀標記依帳號與分頁儲存。登出、帳號變更、背景與離開頁面時沿用既有監聽清理；過期的分頁讀取不會覆寫目前畫面。
