# 九丹十八分支：戰棋技能詳解與模擬勝率

適用分支：`stamina-battle`；戰鬥規則基準：`4584bc46169d49b756283224f4eeccd7f9004b98`。這是**離線策略機器人模擬，並非真人對戰統計**。本次只整理及評估，沒有修改金丹數值、技能或遊戲規則。

## 模擬條件與讀法

- 雙方統一攻擊 A=200、生命 H=1000，開場護盾 0，無法寶與額外被動。此為技能正規化比較，不代表某一境界的正式帳號數值。
- 主表雙方答對率均為 70%；另做 50%／90% 敏感度比較。答題由正式 `R.answer` 結算，答對 +4、答錯 +1，最多兩題／自身回合，體力上限 10。
- 十八分支各對另外十七分支，包含同金丹另一分支，排除自身鏡像。三張正式 PvP 地圖等權；每圖 64 組答題種子，各交換先後手一次：每組對戰 384 場，每分支 6,528 場。未結丹基準另外統計，不放入主排名。
- 主表純勝率 = 勝場／總場；和局獨立列出。積分率 =（勝場+0.5×和局）／總場，**積分率不是純勝率**。十八分支的平均積分率必為 50%，純勝率平均會因和局而較低。
- 95% 區間以 64 組答題種子做 2,000 次叢集重抽樣；同一種子的所有地圖、對手與先後手一起抽取，避免把相關場次當成獨立樣本。區間只描述這套固定策略的種子變異，不包含真人技巧或策略模型的不確定性。50%／90% 各只有 8 組種子，精度較低。
- 本次共 84,000 場：十八分支循環賽 73,440、未結丹基準 6,912、逐關試煉 3,648。全程本機，不呼叫出題／帳號 API，不讀寫正式資料庫。

策略會依現有體力、冷卻、視線與可通行格走位；優先可命中的攻擊與有效治療／護盾，考慮一次後續出招、反擊損失、妖獸紅框及對手隕星。使用自己已知的答對率估算後續體力，不預看後續答案。答案按種子、座位、自身回合數與該回合第 1／2 題固定；50%／90% 欄皆同時變更雙方答對率，用來檢查相對強弱如何改變。每回合至多一次主動接近，再保留一次紅框閃避移動；每次動作都由正式 `tactical-rules.js` 驗證／結算。這是固定的有限前瞻策略，沒有替各分支手動調參，也不等於最優打法，尤其低估多步誘敵、換位陷阱與部分控場價值。

主表中，先手一方勝率 67.36%，和局 0.69%；2.58% 的戰鬥由回合上限結束，平均 15.67 次單方行動。先後手已成對交換以抵銷偏差；**先手本身仍是目前規則很大的優勢**。PvP 上限是合計 60 次單方行動，並非雙方各 60 回合；上限後以生命比例判勝負，護盾不列入比例。未模擬兩分鐘操作逾時。

## 共同規則與舊版差異

1. 普通攻擊花 2 體力，四向擇一，沿該方向兩格各造成 1A；遇障礙停止。每回合攻擊、技能及護身合計最多兩次；移動、答題不占這兩次，但受總操作上限限制。
2. 目前所有金丹技能冷卻都是 2：第 1 次自身回合施放，第 2 次不能，第 3 次可以再次施放。兩次自身回合之間，PvP 還會穿插對手行動。
3. 除自身技能外，射程按曼哈頓距離 |Δx|+|Δy| 計算，且需要視線；斜向兩格等於四點距離。範圍十字會排除阻擋地格，與選點本身的視線限制分開。
4. 普通傷害先受護身減傷，再由護盾吸收，剩餘部分扣生命。免費護身與雷光護體的 40% 減傷不累加。護盾可跨回合保留；一般護身與反擊在下次自身回合開始時重設。
5. 目前戰棋主動技能倍率**不隨金丹品級、元神分支等階而增長**。元神頁面的選擇只決定帶哪個戰棋分支；境界、元嬰與裝備仍可能透過伺服器可信快照改變 A、H 或開場護盾。
6. 舊版自動戰鬥的金丹機率、元嬰連擊、本命神通觸發鏈不額外疊進本戰棋引擎。既有 `simulate-core-winrates.cjs`／`simulate-huashen-winrates.cjs` 呼叫的是另一套引擎，其數字不能直接套用此表。
7. 以最大生命百分比治療／護盾的技能，會受 H/A 比例影響。換成實際高境界、不同裝備或不同元嬰投影，應用新 A/H 重跑；本表不表示所有境界皆有相同勝率。
