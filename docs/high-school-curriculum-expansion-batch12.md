# 第十二批：龍騰及翰林早期非乙版公民第二冊

新增兩冊、13章、40節及其編輯性出題指引。依[三貝德公開108課綱對照](https://www.go100.com.tw/file/108_comparison_table/senior/comparison_civics-2.pdf)的出版社左欄整理，與114學年度乙版分開。早期龍騰為7章24節、翰林為6章16節。對照文件未標明年份；PDF影像無法取得，僅核對結構化文字，未取得原檔雜湊；翰林2-3末字「自由」依語義補足，原文截斷需再核。龍騰另有110年送審課程地圖、章序與此早期對照不同，因此不混用。[龍騰課程地圖](https://www.ltedu.com.tw/Web/Sharefile/EDM/curriculum-map/ghs/civ/map.pdf)。

不以課程對照等同當年課本核證。既有乙版、114年度對照及題庫不動。新增範圍選取、來源防偽、分享與出題限制測試。南一、奇異果高三國文第五冊仍缺目次；國教院審定清單只能證明有冊，不能據此推定章節。
