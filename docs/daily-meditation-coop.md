# 聚星閉關與好友共修

每日五題素養題，依玩家儲存的年級安排國文、英文、數學、自然、社會各一題。每題提供完整的生活情境、文本或觀察資料，要求資訊判讀與兩步理解／推理，不以單純記憶、名詞定義或孤立計算替代。題目透過既有多 API 並行與候補題流程逐題準備，使用相同的答案一致性、格式、知識點與去重檢查，另驗證素養材料及判讀任務。沒有歷史錯題也能開始。答對一題得一星，每人每日最多五星，台灣時間午夜重置。

自己與最多 100 名互為好友的直接好友，已出關的星數相加，上限十五顆。重複好友不重複計算。今日已解鎖的共修進度保留；移除好友後，該好友不再顯示於排行榜。必須先完成自己的五題，才能領取共修獎勵及查看好友成績。

每個節點每天可領一次，星星不消耗。B 為自己出關時境界的閉關基礎靈石，不包含連續天數或法寶倍率；當日升境不改變已固定的共修獎勵。

未出關時，「開始閉關／繼續今日閉關」以頂部全寬金色主按鈕呈現，支援鍵盤焦點、按下回饋及等待狀態；原先重複的開始說明標題與段落刪除。共修星數以十五星進度條呈現，3／6／9／12／15 星為可點擊的獎勵節點；達標亮起、可領取時提示點擊，領過後改為勾選。手機維持同一條橫向進度條，並顯示距離下一節點還差幾星。節點下方簡稱「碎精／團本券／抽獎券」，節點的完整說明保留元嬰碎精、團本入場券及本命法器抽獎券全名。

全領為 6B 靈石、3 元嬰碎精、1 張團本入場券與 1 張本命法器抽獎券。個人境界與連續天數獎勵獨立結算：五題全對獲完整境界基礎獎勵，答對三至四題獲一半基礎獎勵及連續天數加成，零至兩題僅獲 5 靈石；元嬰碎精與元嬰修為加成須五題全對。獎勵金額沿用既有境界數值。元嬰碎精可在未達元嬰時累積，使用門檻維持不變。團本基本每日兩券、持有上限五張；共修額外入場券滿額時折成 2B 靈石。

本命法器抽獎券存於 `users/{uid}.soulboundDrawTickets`，可在契器台明確選擇用券單抽／五連，每抽一張，不搭扣靈石。金丹境開放使用，提前獲得的券保留。同一常駐池、相同機率、相同二十抽武器保底，金幣抽與用券抽共用累計。用券所得原器的實付價格為零。

## 紀錄與重試

- `/api/meditation/{status,start,answer,next,finish,claim}` 驗證 Firebase A 身分，題目由伺服器選取與保存，作答僅提交題目 ID、選項及作答中的累計時間；正誤及星數由伺服器判定。
- `/api/generate-quiz` 的 `meditation-literacy` 模式需登入且已開始當日閉關，科目、年級與題號由伺服器的當日計畫決定。答案保存在私有閉關資料中，答完本題才回傳正解與解析；重複取題沿用同一題，準備失敗可重試，不會另開一場或消耗獎勵。
- `meditationSessions/{date}_{uid}` 保存當日五題與已作答狀態；重新整理可續接，答題回應遺失可重試同一答案，不能換答案或重複加星。
- `meditationDailyResults/{date}_{uid}` 保存當日成績、最高共修星數與已領節點；領取狀態和資源入帳在同一筆交易內提交，與抽取本命法器的票券扣款共用玩家資源交易。
- 個人出關同時更新原有 `dailyMeditation`、每日任務進度及一筆具固定 ID 的 `exam_logs`。部署當日已完成的舊紀錄保留原星數與實際題數，不再發一次個人獎勵。已開始的舊制三題可以按原規則完成一次，隔日使用新制五題。排行榜與個人成績各自顯示實際題數；舊紀錄缺少時間時顯示「—」。
- 好友排行只公開道號、星數與作答時間；星數優先，同星依時間排序，完全同分同時共享名次。時間由前端累計顯示題目且分頁可見、連線中的時段，伺服器限制於實際出題經過時間；不作額外資源獎勵依據。
- 並行的登入／恢復事件共用一筆狀態請求，被動查詢快取一分鐘；切換帳號、跨日或領獎後，舊回應不能覆寫新狀態。重新開啟、手動同步與出關結算後強制取得最新紀錄。答題期間不做狀態輪詢，計時與動畫留在前端。
- 閉關總覽每分鐘更新；已出關、有好友且未達十五星時，在其他頁面每五分鐘查詢好友進度，新節點解鎖時入口亮紅點。沒有好友、未出關、已達十五星或背景分頁不持續查詢好友。切回分頁沿用相同節流，背景分頁也停止作答計時。
- 優先使用前端狀態、短暫快取與伺服器 API，避免非必要的 Firebase 讀取；跨裝置續答、答題紀錄與獎勵入帳仍保留現有持久化與交易驗證。

驗證包含五題正誤與素養出題契約、重新整理續接、回應遺失重試、互為好友／去重／上限、跨日、重複及並行領獎、滿額轉靈石、元嬰碎精與抽獎券入帳，以及票券抽取、保底與扣款回滾。
