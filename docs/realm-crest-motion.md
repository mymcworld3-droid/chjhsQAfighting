## 播放時機

- 首次進入可見區域時播放；圖錄中尚未捲到的紋章會等待。
- 首頁境界變更、重新開啟圖錄或建立新的突破提示時播放。
- 相同 UI 位置、玩家及境界的資料刷新不重播；圖案從 SVG 換成 AI 圖時會播放新圖的出現效果。
- 載入畫面、開場影片與雲幕尚未結束時等待，頁面平移完成後再播放。
- 系統設定減少動態效果時直接顯示完整紋章；動畫只影響圖形及光暈，保留文字與導覽的位置。

`getRealmIconMarkup(realm, className, playerUid)` 的第三參數可識別排行榜、好友及聊天中的固定玩家位置。圖錄與突破提示則依各次開啟的容器播放。

預覽或生成器需要重播時，呼叫 `window.playRealmIconAppearance(icon)`；此 API 同樣遵守可見範圍與減少動態設定。
