# 教師洞天工作頁

管理員及經核准的教師登入後，底部導覽會出現「洞天」。一般帳號不顯示此入口；撤銷教師資格後，重新驗證時移除入口，伺服器拒絕後續教師操作。仙盟建班及教師資格審核沿用既有規則。

## 建立、生成與直接編輯

- 「從教材生成」支援文字及最多八張 PNG／JPEG／WebP 圖片，每張 2 MB、合計 14 MB；沿用既有逐題生成與複核流程，顯示實際生成進度。生成量為 10–14、15–20、21–30 題三種。
- 生成結果先進入編輯器，未儲存前不建立公開洞天。也可使用「自行編題」手動建立 1–30 題。
- 教師可以直接修改題幹、四個選項、正確答案、解析、知識點，新增／刪除／上移／下移題目；直接儲存不需要再要求 AI 批准修改內容。
- 儲存採版本檢查，避免兩個視窗互相覆蓋。改變題目內容或選項順序會更新該題識別碼；正在作答的學生遇到洞天版本更新時需重新進入，避免混用題組。
- 新洞天預設為私人草稿。預覽後勾選確認才能發布，已發布洞天的「儲存修改」會立即套用。可暫停開放或複製為新的私人草稿。
- 教師在原設定頁點「洞天管理」時，也會進入此編輯器。既有非教師的洞天流程保留。
- 學生在教師洞天內的題目回報會送交教師；教師可從名冊的「題目回報」查看、直接改題並填寫處理說明。相同學生對相同版本題目的回報會去重，回報本身不會自動停課或封印洞天。

## 開放及教學設定

| 設定 | 實際行為 |
|---|---|
| 公開 | 開放時間內可出現在隨機洞天名冊，登入玩家可進入 |
| 僅憑代碼 | 不進入公開名冊，取得代碼的登入玩家可進入 |
| 限指定班級 | 只能指定自己獲分配的有效班級；該班學生依即時名單進入，退出或移出後停止存取 |
| 私人 | 僅仍具教師資格的主人可進入；管理員可透過教師管理 API 處理內容 |
| 開始／截止時間 | 伺服器在進入及結算資格建立時判定；老師試玩自己的已發布洞天可不受期間限制 |
| 打亂題序 | 每次進入調整順序；伺服器按唯一題目代碼對應答案並計分 |
| 打亂選項 | 可隨機排列，也可使用編輯器內的固定選項順序 |
| 解析時機 | 每題作答後顯示，或整份完成後才顯示正誤及答案解析 |
| 及格標準 | 0–100% 正確率；伺服器保存達標結果，結算畫面顯示達標狀態 |

另可設定洞天名稱、介紹、作答說明、科目、程度、難度及最多八個標籤。長說明以可展開區塊呈現，沿用既有答題畫面及白色數學公式。

發布後可複製洞天代碼。學生到「設定 → 洞天 → 以洞天代碼進入」輸入代碼；私人、未發布、尚未開始、已截止或無班級權限的內容，知道代碼也不能進入。

## 與班級作業連動

預覽內可將題組複製為所管理班級的作業草稿，另設作業截止時間。到「仙盟 → 班級」確認固定題組後發布，使用既有的續答、首次成績、訂正與匯出流程。洞天之後修改、暫停或調整開放範圍，不會改寫已派作業及成績。

## 資料及權限

內容與名冊繼續使用 BD 的 `dongtians`／`dongtianIndex`，新增 `teacherManaged`、`version`、`visibility`、`classId`、開放期間及 `settings`。新增 `POST /api/teacher/dongtian`；主專案登入驗證後，從 A 的管理員紀錄與已核准教師紀錄核對資格，再處理本人洞天。管理員可按代碼處理教師洞天。

公開名冊會過濾私人、代碼限定、班級限定、未到時間及已截止內容。一般 D1 瀏覽器端點不能讀取教師洞天全文或直接改寫教師洞天的標記、題組與開放範圍；只能透過有權限檢查的領域 API。舊 A 區洞天副本也不作為一般玩家內容讀取來源。既有一般公開洞天維持原入口與獎勵規則。

D1 瀏覽器權限由本次程式一併更新。使用 Firestore 時，A／BD 外部規則也須拒絕一般瀏覽器直接讀寫 `teacherManaged` 全文與私有名冊，公開內容及教師編輯均經領域 API；程式庫未包含 A／BD 的外部規則部署設定。

## 驗證

- `node --test tests/teacher-dongtian.test.cjs`：教師資格、所有權、直接改題、版本衝突、開放範圍、時間與班級限制、隨機題序計分、達標、固定作業副本及原始資料端點防護。
- `node scripts/check-teacher-dongtian-ui.cjs`：Playwright 本機驗收導覽、圖片與文字串流生成、直接改題、預覽發布、班級限定與私人切換、作業副本、橫直式導覽及帳號隔離。
- 原有洞天及全專案回歸測試，並重建各分支資源版本。
