# 答題修為加成

- 每把持有的 Lv.20 武器永久增加 30% 正確作答修為，不需裝備，重複武器副本不重複計數。
- 每累積十道正確作答觸發頓悟；接下來三道正確作答各額外 +100%，答錯、離線、切換模式不消耗，頓悟期間不累積下一輪。
- 兩項加成相加，作用於原本正確作答修為（含既有學習加成），不改答錯扣分、體力、通關固定獎勵。用百分之一點的整數餘數保存，整數才入帳。
- 適用問道試煉、自由問道、單人武器副本及已存在的合作副本答題；閉關、洞天與其他結算型獎勵保持原規則。
- 戰棋和合作副本由伺服器在既有答題交易內讀取武器、結算及保存 stats.answerCultivationV1；自由問道沿用既有客戶端玩家交易及經登入驗證的武器快照，並在交易內依最新遠端進度計算頓悟及餘數。
