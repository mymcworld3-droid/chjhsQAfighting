# 仙位化身挑戰

九州五大仙改以擊破守擂化身奪位。原在榜者保留仙位；舊連答紀錄不再作為勝負條件。尚未保存化身的舊席位，第一次受挑戰時使用該仙主當時儲存的配裝；空位由固定 NPC 鎮守。

- 渡劫（1268 修為）可不限次挑戰，依原學制分組、仙位科目出題；1868 修為且在榜才是真仙。一人同時僅能持有一席。
- 每場最多 24 回合，雙方生命由實際攻擊、境界生命、調御金丹、元嬰養成、神通、擁有且已裝備的法器投影。共用現有鬥法引擎，戰鬥耗血不寫回永久生命。
- 答對才能出手；答錯只失去本回合出手機會。化身每回合依固定風格自動行動；重擊先手，其他行動由挑戰者先手。
- 強攻為 120% 基礎攻擊，並釋放蓄力。守勢為 70% 基礎攻擊，同回合將化身基礎攻擊降為 45%。蓄力為 35% 基礎攻擊，每層為下次強攻增加 65%，最多兩層。戰術改變攻擊力，金丹、元嬰、法器的獨立加傷依既有規則結算。
- 化身強攻風格依序進攻、進攻、重擊；續戰風格依序守勢、調息、進攻；反擊風格依序守勢、重擊、進攻。守勢將挑戰者基礎攻擊降至 55%，自身攻擊 65%；調息回復 7% 最大生命、攻擊 50%；重擊攻擊 155%。每回合事先顯示意圖。
- 24 回合內須擊倒化身且自己存活才奪位；逾時或同歸於盡由仙主守位。自己的仙位可試陣，沒有額外資源獎勵。
- 仙主可保存目前配裝並選擇守擂風格，離線也能守擂。平時更換裝備不會自動改變已保存化身。更新化身或席位易主後，進行中的舊目標挑戰只能完成戰鬥，不能覆蓋新席位。
- 暫離可在開戰後一小時內續戰；同時只保留一場。結束挑戰可立即重開。每回合答題紀錄和結算一起保存，網頁關閉也不丟紀錄。

## 資料與驗證

`immortal-challenge-api.cjs` 提供已驗證玩家的 status、start、configure、answer、abandon；`immortalAvatarSessions/{uid}` 保存有期限的單場快照與一個待答題目，不對瀏覽器資料 API 開放讀寫。

`/api/generate-quiz` 的 `immortal-avatar` 模式由單場資料決定科目、學制和題號。選項由伺服器洗牌，正解及解析放在與玩家、場次、題號綁定的加密票證；結算前不回傳正解。重複取題重用待答題目，同一答案重送回傳同一結算。用戶端不能提交勝利、HP 或任意戰力以奪位。

奪位事務重新驗證修為、學制、其他四席及目標化身修訂。勝出的出戰配裝以開戰前的滿血、初始護盾與零戰鬥計數保存為新守擂化身。既有瀏覽器連答寫榜路徑已關閉；顯示名稱同步與本人放棄仙位仍可沿用原權限。
