# 演武試煉

從「修煉 → 狀態 → 綜合戰力 → 演武試煉」開陣。金丹境（含永久解鎖）可進入；已完成副本或真仙玩家亦可隨時遊玩，不需額外答題、門票或體力。

- 共 100 層，敵方攻擊、生命逐層增加，第 5 層起出現守陣金丹。依守衛顯示的進攻、重擊、守勢、調息意圖，選擇強攻、守勢、蓄力。
- 使用正式鬥法引擎的金丹、元嬰、神通、本命法器、暴擊、連擊、護盾、反傷等結算。戰力數字是配裝總覽；實際攻擊與生命取自 `trustedRaidPlayerSnapshot`，不把戰力數字直接作傷害倍率。
- 強攻為 120% 基礎攻擊，釋放每層 +65% 的蓄力；守勢為 70% 攻擊，當回合敵方基礎攻擊降為 45%；蓄力為 35% 攻擊，最多兩層。條件加傷沿用既有鬥法規則。
- 開陣時鎖定已保存且擁有的配裝，停用金丹的效果不計入。換裝後重新開陣即可試用新配裝；本次挑戰中途換裝不改變已保存戰場。
- 每層最多 24 回合，擊破守衛且自己存活才通過；逾時或同歸於盡均不通過。下一層重置生命、護盾、回合計數、蓄力與每場技能狀態。
- 每通過五層解鎖下一個起點，例如通過第 10 層可由 11 層重開；百層全通後可由 96 層重試。最高通過層數、累計通過次數與演武稱號永久保存。
- 稱號依最高紀錄為初入演武、入陣修士（5 層）、百戰修士（20 層）、演武宗師（50 層）、萬象破陣者（100 層），顯示於演武台。
- 不發放修為、靈石或材料，避免無答題戰鬥成為自動刷養成資源的捷徑；失敗也不扣永久生命或資源。關閉可暫離，兩小時內可續戰，逾時保留最高紀錄並重新開陣。

`martial-trial-api.cjs` 在伺服器保存 `martialTrialStates/{uid}`，不開放瀏覽器資料 API 讀寫。GET status 與 POST start／turn／next／abandon 都驗證主專案身分。玩家不能提交攻擊、生命、勝負或最高層數；每次操作都帶唯一識別碼與當前場次、層數、回合，交易內核對並防止重送／併行重複結算。回合最短間隔 300ms。

驗證包含主專案登入、解鎖、配裝權威快照、戰術效果、勝敗、下一層滿血、五層起點、重送、併行、過期、換裝鎖定、百層邊界、私有紀錄防偽，以及實際瀏覽器的暫離、續戰、網路重試與手機版操作區可見性。
