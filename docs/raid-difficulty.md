# 清霜試煉固定難度

沈清霜固定為 4,800 HP、70 基礎攻擊。每 18 秒出手，70%／30% 血量切換劍式；隊伍人數、玩家境界、戰力、裝備及退出均不調整 Boss 數值。新開戰使用固定難度，已開戰房間保留原有數值，避免中途突變。

校準以三人正常通關、單人需要部分元嬰節點滿級為目標。通關仍受答對率、答題速度、金丹品級與法寶影響，不設單人配點門檻。

回歸測試使用真正的伺服器答題結算與 Boss 時鐘，每種丹性測試 200 場、共 5,400 場。基準是每人 200 攻擊、1,000 生命、9 品金丹、無法寶，每 20 秒作答一次、80% 答對率。三人使用無元嬰配點的金丹角色；元嬰單人測試使用神魄 10、靈體 10、守元 5、護命 10（85 神識），不必點滿整棵樹。測試也確認一至四人的房間 API 開戰數值相同。

這些通關率是特定節奏與配裝的模擬結果，並非保證所有實際隊伍都能通關。較強法寶、高品金丹與更快作答仍可能讓單人提早通關。
