# 體力分支：功法修煉

適用：`stamina-battle`。此功能只替換修煉頁面的入口與玩法，不刪除已有的修為、金丹、元神或舊裝備持有資料。

## 玩家流程

1. 點選底部「修煉」進入功法閣；原本的修煉場景、金丹及元嬰分頁不再顯示，也不主動重新渲染。
2. 選擇劍修或體修。首次選擇免費習得該派一本入門功法；若已達煉氣境（修為 ≥ 1），自動裝備第一招。凡人境可先取得功法，但升至煉氣後才能裝備及施放。切換流派不清空已有功法或熟練度，也不重複取得免費功法。
3. 完成問道試煉 PvE 關卡（必須正常擊敗靈獸、至少答對一題、並成功結算）後，若仍有未收錄功法，30% 機率得到一本未收錄功法。連續三次合格通關未掉落時，下一次必掉；同派書籍優先權為 70%，且仍有機會取得另一派。
4. 每本功法固定三個技能；使用該功法技能 **最後一擊擊殺** PvE 靈獸才增加熟練 EXP。獎勵依靈獸的境界（由當場試煉關卡決定）分為 50–550 EXP，越高境界越高。功法從 Lv. 1 開始，升級需求為 `40 + 20 × (目前等級 - 1)` EXP；Lv. 5、Lv. 10 分別滿足第二、三招的**功法等級條件**，仍須達到各招指定的修士境界。普攻、金丹攻擊與 PvP 擊殺不提供功法經驗。
5. 可跨功法、跨劍修與體修自由裝備至多三種**不同且已解鎖**的技能。空裝備欄合法。同名共用招式只能占一個技能欄，可切換所屬功法；擊殺熟練度計入裝備時選定的功法。重新進入未完成的試煉時，會同步裝備並保留關卡進度。
6. PvE **左下充能圓盤第二層**直接顯示目前最多三招已裝備功法技能，點擊一招後在地圖選擇攻擊目標；右側圓盤只負責「攻擊／移動／結束回合」及目標選擇，沒有額外功法彈出選單。未裝備任何功法技能時，左圈預設只有「普通攻擊」；只要裝備一招以上，普通攻擊就被所有裝備技能取代、不再顯示也不能使用。PvP 在操作區直接列出已裝備技能，沒有裝備時才顯示普通攻擊。金丹技能從所有體力戰棋戰鬥停用。所有普通攻擊／功法技能共用每回合兩次出手、10 點體力上限及技能冷卻。

## 功法與招式

| 流派 | 功法 | 第一招（Lv. 1） | 第二招（Lv. 5） | 第三招（Lv. 10） |
| --- | --- | --- | --- | --- |
| 劍修 | 流風劍訣 | 流風斬 | 突進橫斬 | 遠線破擊 |
| 劍修 | 御劍真訣 | 流風斬 | 召劍 | 遠線破擊 |
| 劍修 | 八方劍典 | 流風斬 | 交叉劍斬 | 八方合劍 |
| 體修 | 玄嶽鍛體訣 | 碎岩拳 | 震嶽罡勁 | 崩山重拳 |
| 體修 | 龍象真身訣 | 龍象衝拳 | 金剛護體 | 龍象震天 |

**所有功法第一招消耗 2 體力**。流風劍訣保留既有熟練度與裝備欄。原青霄劍典的熟練度與裝備欄自動沿用至八方劍典。御劍真訣透過試煉掉落取得。每級所需 EXP 遞增 20 點：Lv. 1→2 需 40、Lv. 2→3 需 60、Lv. 3→4 需 80、Lv. 4→5 需 100；Lv. 5 累積 280 EXP、Lv. 10 累積 1080 EXP。

藏經閣只展示已獲得的功法，取消頂部大型介紹區，改以每本功法的等級、當級 EXP 進度條與下一招解鎖等級呈現。招式射程、體力、倍率、冷卻與 EXP 公式都在 `public/cultivation/manual-rules.js` 定義。


## 劍招的戰場判定

| 招式 | 體力 | 判定 |
| --- | ---: | --- |
| 流風斬 | 2 | 選一個正向，攻擊前方直線三格。 |
| 突進橫斬 | 5 | 選直線四格內可通行的落點，沿路遇到角色或障礙即無法通過。抵達後連斬前方一排三格，兩段合計 1.8 倍攻擊。 |
| 遠線破擊 | 4 | 劍氣沿正向延伸至障礙或地圖邊界，沿途命中各一次。存活的敵人從最遠的開始推至可落腳的最後一格，受其他角色或障礙阻擋時提前停下。 |
| 召劍 | 3 | 首次在自身直線三格內的空地召劍，飛劍留到本場戰鬥結束。再次施放時從飛劍所在格直線移動最多四格，穿過的敵人各受一次傷害。召喚和移動各占一次出手，可同回合連用兩次。 |
| 交叉劍斬 | 4 | 選三格內可見的中心，四條斜向各延伸兩格。中心最多兩段，完整命中合計 1.6 倍攻擊。 |
| 八方合劍 | 6 | 選四格內可見的中心，正向各三格、斜向各兩格。中心最多八段，完整命中合計 2.4 倍攻擊。 |

## 技能境界門檻

技能需要同時滿足 **功法 Lv. 1／5／10** 與個別的 **修士境界**，才能裝備及施放。

| 功法 | 第一招（Lv. 1） | 第二招（Lv. 5） | 第三招（Lv. 10） |
| --- | --- | --- | --- |
| 流風劍訣、玄嶽鍛體訣 | 煉氣（修為 1） | 築基（修為 6） | 金丹（修為 28） |
| 御劍真訣 | 築基（修為 6） | 築基（修為 6） | 金丹（修為 28） |
| 八方劍典、龍象真身訣 | 築基（修為 6） | 金丹（修為 28） | 元嬰（修為 68） |

裝備 API 拒絕未達門檻的技能；前端分別顯示功法等級與境界未達情形。修士境界以現有 **已達最高修為** 的伺服器規則判定，並遵守凡人（0）、煉氣（1）、築基（6）、金丹（28）、元嬰（68）等門檻；不以玩家傳入的屬性、前端選項或本場靈獸境界判定。

## 靈獸境界與 EXP

試煉每關產生的靈獸以 **關卡階段** 確定境界，同一關的敵人境界相同，與物種不同。獎勵只在使用功法技能打出最後一擊時發放：

| 關卡 | 靈獸境界 | 每隻 EXP |
| --- | --- | ---: |
| 1–4 | 煉氣 | 50 |
| 5–9 | 築基 | 70 |
| 10–19 | 金丹 | 100 |
| 20–34 | 元嬰 | 140 |
| 35–54 | 化神 | 190 |
| 55–79 | 煉虛 | 250 |
| 80–109 | 合體 | 330 |
| 110–149 | 渡劫 | 430 |
| 150+ | 真仙 | 550 |

## 資料與保護

- `tacticalManuals/{uid}` 保存功法總經驗 `books[id].exp`、掉落保底、所選流派及最多三個技能 ID；所有寫入只能由後端以登入帳號進行。舊版 `books[id].kills` 在首次寫入時自動轉換為 EXP，並保留原先已解鎖招式（原 3 次擊殺→至少 Lv. 5、8 次擊殺→至少 Lv. 10）。
- 新版戰場以 `tacticalBattleRooms/{id}.manualExp` 與 `manualAppliedExp` 記錄各功法本場累積 EXP 與已領 EXP，避免指令重送重複領取；舊版進行中的戰鬥仍支援 `manualKills` 與 `manualApplied`，按舊版每擊殺 50 EXP 完成結算。戰場每次死亡事件只計入一次，且計算都在伺服器完成。
- `tacticalBattleRooms/{id}.manualDrops` 保存該關已結算的掉落結果。發獎、試煉下一關進度、功法授予與房間結束共同使用資料庫交易；同一關不能靠重送領取多次。
- 客戶端不能自行指定武功傷害、掉落、熟練度、靈獸境界、正解或解鎖條件。伺服器用 `training-access-rules.js` 的玩家修為門檻校驗裝備資格，新開戰場時固定技能快照，戰鬥施法時依角色修為再次檢查技能境界。
- 金丹、元嬰等原有伺服器持有資料繼續保留，不會清空玩家原本修為和金丹，但金丹技能無法再透過體力戰棋操作：舊客戶端傳送的 `type:"skill"` 也會被伺服器拒絕。
- 沒有刪除舊金丹、元神資料，也不會把舊功法重新抽取；只在既有功法的熟練紀錄上進行可重複執行的升級轉換。

## API

- `GET /api/tactical/manuals`：回傳本人功法及技能解鎖狀態。
- `POST /api/tactical/manuals/school`：`{school:"sword"|"body"}`。
- `POST /api/tactical/manuals/equip`：`{skillIds:[...]}`，最多三種已解鎖技能。
- `POST /api/tactical/action`：`{type:"manual",skillId,x,y,roomId,revision,requestId}`；有裝備功法時拒絕 `type:"attack"` 普通攻擊，未裝備時允許；全面拒絕 `type:"skill"` 金丹技能。移動、護身、結束回合維持原本 API。
