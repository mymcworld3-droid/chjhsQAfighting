# 體力分支：武器修煉

適用：`stamina-battle`。武器與招式規則共用 `public/cultivation/manual-rules.js`，伺服器使用相同目錄驗證。

## 武器與技能

| 武器 | 類型 | 原生等階 |
| --- | --- | --- |
| 流風靈劍 | 劍 | 煉氣 |
| 御靈飛劍 | 劍 | 築基 |
| 八方天劍 | 劍 | 金丹 |
| 玄嶽圖騰 | 圖騰 | 煉氣 |
| 伏虎圖騰 | 圖騰 | 築基 |
| 龍象圖騰 | 圖騰 | 金丹 |

八方天劍、龍象圖騰由元嬰改為金丹，原本的 ID、EXP、技能與裝備資料保留。武器本身可以有等階；**技能沒有境界條件**，只依該款武器熟練 Lv.1、5、10 領悟三招。凡人修為也可裝備、施放及強化已解鎖的技能。玩家與靈獸的境界系統仍用於原有修為、試煉階段和 EXP。

最多裝備兩件不同款武器，兩個欄位平等，沒有主武器。技能由武器熟練度自動帶入；戰鬥中未解鎖的技能不出現。空武器欄隱藏，弧形操作輪依可用項目平均分配角度；完全沒裝備時才顯示「攻擊」。

## 入口與裝備

修煉頁只列已持有武器，點選卡片開啟修煉彈窗，顯示圖片、熟練度、招式與強化。升級與切換時保留未變更圖片的 DOM，避免閃爍。兩個裝備欄仍在收藏區下方；單人試煉／武器副本進行中可調整，切換不消耗體力，伺服器同步所有進行中的單人房間。多人鬥法及合作副本進行中禁止更換武器。

首次選擇劍修或體修免費取得入門武器，切換流派保留已持有武器與 EXP、不重複發放入門獎勵。原先三組技能配置的 API 及資料遷移只供舊版本相容；新版操作使用雙武器。

## 熟練度、強化與傷害

- 每件已持有武器的實際熟練等級增加同等永久攻擊力；所有持有武器合計，不因是否裝備或重複持有而重複計算。
- Lv.1 起，升下一級需要 `40 + 20 × (目前等級 - 1)` EXP；Lv.5 累計 280 EXP、Lv.10 為 1080 EXP，Lv.20 上限為 4180 EXP。
- Lv.1–10 可用靈石補足缺少的 EXP，每 1 EXP 花費 2 靈石。Lv.10 以後只可由戰鬥獲得 EXP；不能購買超過 Lv.10 的等級。
- 每招有獨立強化 Lv.1–5，升下一級花費 `200 × 目前招式等級` 靈石。報價及目標等級由伺服器核對，重送不重複收費。
- 武器技能無冷卻，仍受體力、出手次數、地形與射程限制；金丹神通不能透過新版戰棋操作。
- 修煉氣象為 Lv.1–4 初息、5–7 凝紋、8–9 盛氣、10–19 大成、20 圓滿。靈脈只顯示 Lv.1–10，保留 1／5／10 三個節點，不延伸到 Lv.20。
- 升級、實際解鎖及新武器演出只根據伺服器前後資料。戰鬥中的門檻試算明示暫估，不自行發獎或宣告技能已解鎖；遵守減少動態效果設定。

## 戰鬥 EXP

以武器技能打出最後一擊擊殺靈獸，該款武器獲得對應 EXP。普通攻擊、金丹攻擊與 PvP 擊殺不提供此熟練經驗；部分一般試煉任務另有既有參與 EXP。

| 靈獸關卡階段 | 靈獸境界 | 每隻 EXP |
| --- | --- | --- |
| 1–4 | 煉氣 | 20 |
| 5–9 | 築基 | 35 |
| 10–19 | 金丹 | 55 |
| 20–34 | 元嬰 | 85 |
| 35–54 | 化神 | 120 |
| 55–79 | 煉虛 | 170 |
| 80–109 | 合體 | 235 |
| 110–149 | 渡劫 | 320 |
| 150 以上 | 真仙 | 430 |

房間 `manualExp` 記錄累計 EXP，`manualAppliedExp` 作為已入帳收據；舊 `manualKills` 仍依相容公式換算。重複行動、重送、重新結算不重複入帳。戰鬥即時浮窗和結算回顧只讀伺服器帳本；最新等級由 `/api/tactical/manuals` 取得。

## 武器取得與等階

一般問道試煉只掉落尚未持有的原生煉氣武器（流風靈劍、玄嶽圖騰），不隨關卡提升掉落境界。保留原有 30% 掉落、連續三次未掉落後下一次保底、首關新手獎勵；兩款皆已持有後不再掉落武器，也不再累積保底。新加入的[單人武器副本](weapon-dungeons.md)使用獨立票券、難度與 30% 當階／20% 下一階／50% 無武器的掉落規則。

副本掉落沿用六款武器的 ID、圖片與招式，每款境界固定。重複取得自動精煉，最高五星，每星本武器招式傷害 +5%。既有跨境界持有數量合併到原生境界，原熟練度與技能強化不變。

## API 與安全

`/api/tactical/manuals` 回傳持有武器、等級、EXP、解鎖與升級報價；`/school` 領取入門武器，`/loadout` 以 `index:0..1,weaponId` 裝卸，`/upgrade` 與 `/upgrade-skill` 驗證報價後扣款。

技能來源與熟練度由伺服器驗證；客戶端不能指定傷害、掉落、EXP 或解鎖條件。舊進行中房間的 `manualRulesVersion` 升至 2，補齊無技能境界門檻的雙武器快照，不重置生命、體力、題目或關卡進度。武器原生等階調整不清空修為、金丹、元神與原有持有資料。
