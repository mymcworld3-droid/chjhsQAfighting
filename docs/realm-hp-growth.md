# 境界突破：永久最大生命加成

從**築基**往後，每次晉升一個大境界，永久提高最大生命值 **100** 點。築基本身不加血；到金丹第一次 +100。各境界門檻使用共用的 `training-access-rules.js`：

| 境界 | 修為門檻 | 累計額外生命 |
| --- | ---: | ---: |
| 煉氣／築基 | 0／6 | 0 |
| 金丹 | 28 | +100 |
| 元嬰 | 68 | +200 |
| 化神 | 188 | +300 |
| 煉虛 | 428 | +400 |
| 合體 | 788 | +500 |
| 渡劫 | 1268 | +600 |
| 半仙 | 1868 | +700 |

以已達到過的最高境界作為加血判定來源；扣修為不會撤回已取得的生命。尚未遷移的舊玩家沿用既有境界解鎖回推。

**生命投影（不修改資料庫中的 `stats.maxHp`）**：

1. 玩家永久保存的基礎最大生命值（預設 1000）＋境界生命獎勵。
2. 加上元嬰生命分支的固定最大生命值。
3. 加上裝備固定生命後，再乘裝備最大生命百分比倍率。
4. 鬥法、團本、狀態頁都採相同順序；戰力展示計入境界生命，但裝備分數不重複計算。
5. 在舊存檔內仍只保存原有生命基數，切換場景或重新登入不會重複加血。

例如化神期、沒有生命法寶、元嬰生命分支滿級，最大生命 = 1000 + 300 + 250 = **1550**。

驗證：`node --test tests/realm-hp-growth.test.cjs`。化神十八分支交叉模擬：`node scripts/simulate-huashen-winrates.cjs 0.7 400 350`。
