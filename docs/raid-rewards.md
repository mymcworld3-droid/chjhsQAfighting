# 團本獎勵

現行素材經濟固定只保留四項，而且四項都只能由團本「產生」：

- **秘境玄髓**：煉器素材，可直接投入八方煉器陣；可在玩家交易市集轉手。
- **清霜劍魄**：沈清霜團本煉器素材，可直接投入八方煉器陣；可在玩家交易市集轉手。
- **淬靈玄印**：第二煉必要印記，不佔煉器素材格，綁定玩家、不可交易。
- **玄天道印**：第三煉必要印記，不佔煉器素材格，綁定玩家、不可交易。

問道、洞天、商店與一般活動不再掉落或販售任何煉器素材。舊的玄鐵、靈木、靈晶、妖丹等材料退出現行目錄與配方，不再顯示於背包或煉器選擇。

## 清霜試煉通關

每次通關固定：
- 秘境玄髓 ×2
- 清霜劍魄 ×1
- 淬靈玄印 ×2
- 玄天道印 ×1

每日首勝額外：
- 秘境玄髓 ×1
- 淬靈玄印 ×1
- 玄天道印 ×1

首次通關額外：
- 清霜劍魄 ×1
- 永久紀念「清霜劍印」

因此第一次通關且同時是當日首勝時，合計為：秘境玄髓 ×3、清霜劍魄 ×2、淬靈玄印 ×3、玄天道印 ×2。

## 合作機制

每次 Boss 出招後開啟新的合作窗口，只計算不同玩家：

- 2 名不同隊員答對：完成「同心破陣」，Boss 下一式傷害降低 45%。
- 3 名不同隊員答對：觸發「三才合擊」，額外造成 240 團隊傷害。
- 同一玩家在同一窗口答對多題仍只算一名貢獻者。

Boss 基礎 HP／攻擊不隨隊伍人數縮放；單人仍可挑戰，但無法觸發多人門檻。

## 素材資料來源

素材目錄改為前端固定規則，不再由 Firebase `gameConfig/materialCatalogV1` 即時同步；自動素材掉落模組已停用。玩家市集可以交易秘境玄髓與清霜劍魄，但交易本身只是既有素材在玩家之間轉移，不會新增素材供給。
