# 團本獎勵

- 新版伺服器接受的每次答對：修為 +1、靈石 +20。入場時元嬰以上另得神識 +1，戰敗亦保留。答錯不扣這些收益。元嬰答題修為加成目前用於一般問道，團本依這份固定收益表。
- 通關每人淬靈玄印 2 枚、玄天道印 1 枚；額外同入場境界的普通素材 3 個（兩種，2 + 1）。素材 ID 來自既有材料表，不含終局稀有材料，完整管理員材料表移除或改境界的項目不發放。
- 每日首勝額外兩種道印各 1 枚。依可信 C 房間的完成時間，台灣時間午夜換日。同日多個房間僅一次。首度通關保存永久「清霜劍印」，團本入口可查看，沒有戰鬥加成。
- 人数不影響難度或個人獎勵。沒有新增勝利修為倍率、傷害屬性或 Boss 調整。

## 交易與相容性

C 的 `members[uid].learningCorrect` 只累加新版接受的答對，舊 `correct` 不補發修為／靈石。A 的既有 `raidSpiritClaims` 同時保存 `settledCorrect` 和 `settledLearningCorrect`，只發未結算差額；舊神識收據保留。房間輪詢、重連可補上暫時失敗的 A 入帳。

A 玩家 `raidLearningRewards` 是累積已發修為／靈石標記，前端僅鏡像未見過的新增差額，不用歷史金額覆蓋玩家後來消費的靈石。勝利收據 `raidRewardClaims` 與背包、`raidProgress`、`raidDailyClaims` 在同一 A 交易處理。舊勝利收據維持原獎勵，不重发新額外奖励。重領只回傳原收據，前端另讀當前背包，避免把已消耗道印復原。

結算顯示個人答題收益及待入帳狀態、素材用途、首勝加贈和紀念物，可跳轉煉器。暫時斷線時請留在結算頁或重連重試；不提供跨專案原子交易或背景永久補發保證。

## 驗證

測試涵蓋簽名答案判定、答錯、重送、亂序累積結算、A 入帳失敗後戰敗輪詢補發、舊收據、台灣午夜、同日並行首勝、目錄變更、帳號切換及已消耗道印。`scripts/capture-raid-rewards.cjs` 使用真實結算 renderer 及合成房間資料，截取 1440×900 / 390×844 的勝利、戰敗、待入帳、重試、已領取畫面及獎勵區，檢查水平溢出。截圖是隔離 UI 驗證，並非正式 Firebase 帳號實戰。
