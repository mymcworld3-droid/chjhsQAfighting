# 流派節點重新規劃（cultivation-reboot）

## 結構與原則
- 流派：劍修、體修、法修、悟道修。
- 境界：築基、金丹、元嬰、化神、煉虛、合體、渡劫、半仙。
- 每境界 **7 點研修**，保留兩路各 3 個節點、匯入 1 個大節點的結構；第一境界前保留第 0 節點「起點」。
- 小節點與大節點 **每個只給一項屬性／效果**；不把攻擊力和其他加成綁在同一節點。
- 兩條路線都能修到攻擊力；每境界選擇任一路線修到第 3 節點，即可在點數充足時修習大節點。
- 後續境界的第 1 小節點需要前一境界的大節點。後續第幾境界仍由原有修為與天劫規則決定。
- 大節點擁有獨立名稱、實際數值效果及說明。所有效果使用現有戰鬥系統支援的效果類型，**不修改戰鬥及答題演算法**。

## 兩路的玩法差異

| 流派 | A 路線 | B 路線 | 玩法主軸 |
| --- | --- | --- | --- |
| 劍修 | 破鋒：攻擊／暴擊率／暴擊傷害 | 迴劍：攻擊／連擊率／連擊傷害 | 爆發與連擊 |
| 體修 | 鎮嶽：生命／固定減傷／攻擊 | 回震：攻擊／答對護盾／反傷 | 生存與反制 |
| 法修 | 雷殛：攻擊／真實傷害／暴擊率 | 符陣：攻擊／連答傷害／普通傷害 | 真傷與連答輸出 |
| 悟道修 | 觀心：攻擊／吸血／生命 | 歸元：攻擊／減傷／反傷 | 持續回復與逆轉 |

每個境界的小節點依階段冠上不同名稱；固定攻擊／生命等整數加成隨境界適度成長，機率與百分比則維持可控增幅。

## 相容性
- 節點 ID 維持 `foundation-a1`～`immortal-seal` 等原格式，已點亮的節點不會被清除。
- 已有節點依新配置重新計算加成：**舊存檔的節點會保留點亮狀態，但加成數值／類型可能改變**，因此這份規劃僅在實驗分支導入。
- 不修改後端儲存結構、學習點數累積、境界門檻、天劫規則、戰鬥演算法及問答判定。
