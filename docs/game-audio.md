# 遊戲音效

目前八個檔案合計約 82 KB，皆為單聲道 MP3，已統一峰值、縮短尾音並加入淡入淡出。

| 檔名 | 共用用途 |
| --- | --- |
| ui-click.mp3 | 可信任的實際按鈕點擊；程式觸發的 click 不播放 |
| cloud-whoosh.mp3 | 導覽換頁、訓練場景雲幕與飛船入口 |
| answer-correct.mp3 | 悟道、閉關、悟道試煉、鬥法、團本、問鼎答對 |
| answer-wrong.mp3 | 各模式答錯、戰鬥失敗及煉器操作未完成 |
| combat-impact.mp3 | 鬥法／團本命中、反擊、暴擊與開始煉製 |
| spirit-pulse.mp3 | 護體、金丹觸發、元嬰升級、小境界提升 |
| reward-chime.mp3 | 閉關、任務、一般抽獎獎勵與好友通知 |
| grand-reveal.mp3 | 大境界突破、本命法器、開爐與勝利結果 |

## 播放規則

- 所有事件使用 `globalThis.QAGameAudio?.play(id, options)`，不得另建 AudioContext。
- 答題使用 `.answer(correct, stableEventKey)`；金錢與修為的逐項增加不播放獎勵音。
- 僅保留一個前景音效。替換時最多有一個退出來源，先淡出 18 ms，再讓新音效開始發聲；總來源數不超過二。
- 18 ms 內的同批操作只保留最高優先的一個提示；沒有播放佇列。
- 突破／稀有結果優先於獎勵、答案、技能、命中、轉場與點擊。
- 同檔及同類音效有冷卻時間。結果、答題與命中使用穩定事件鍵，避免快照、重連與重複結算提示重播。
- 下載或解碼超過 200 ms 的舊請求直接捨棄，不延遲補播。
- 首次可信任的操作才解鎖唯一 AudioContext；初次解鎖不補播先前事件。
- 換頁停止前一頁音效；靜音、音量零、背景、離頁及帳號資料重新載入皆清除正在播放和準備中的音效。
- 僅音效開關控制音效，不受背景音樂開關影響。設定頁的開關與音量保存於這台裝置。
- 無法播放、離線或缺少音檔不阻擋遊戲與已提交的獎勵。

`QAGameAudio.diagnostics()` 可檢查目前提示、來源上限、已解碼音檔及靜音狀態；不含玩家個人資料。

修改音檔或程式後執行 `npm run build:module-versions`，MP3 也會納入逐檔版本快取。
