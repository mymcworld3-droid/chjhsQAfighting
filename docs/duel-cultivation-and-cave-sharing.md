# 鬥法答題修為與洞天分享

新建立的 v2 鬥法房間使用 `battleCultivationVersion: 1`，每回合的雙方答題正誤保存於 `battleCultivationLedger`。提交答案與記錄修為資格在同一筆房間交易內完成，同一角色／回合只記一次；戰鬥結算補齊雙方紀錄，換題不清除紀錄。

答對依入場修為給基礎修為：金丹前每題 1、金丹起每題 2。答錯、逾時不增加獎勵池；即使答對後未能出手，仍計入該題。雙方答題修為相加後，勝者取得全額、敗者取得一半；平局雙方各得一半，保留 0.5 修為。投降／斷線也計入當回合已提交的答案。靈石仍為勝者 500、敗者 200、平局 0。

瀏覽器與 `/api/battle/reward` 共用 `battle-cultivation-rules.js`。後端以 C 專案的房間紀錄計算修為，不接受請求指定的獎勵或 UID；A 專案的每人／每場 receipt 保證重試只入帳一次。沒有新修為版本的既有房間保留原制，已發放 receipt 也保留原值。這沿用現有由客戶端提交房間狀態的鬥法架構。

「我的洞天 → 洞天管理 → 分享到聊天室」是唯一的分享入口。主人按下按鈕後重新讀取洞天，僅允許分享自己的開放中正式洞天，再以登入主人的資料寫入 A 專案 `global_chat`。不自動發布；成功後本次管理畫面的分享按鈕停用，失敗則可重試。

聊天室的 `dongtian-share` 訊息提供進入按鈕。玩家點擊後讀取最新洞天內容，刪除、封印、教學範例及未完成題目無法進入；重複點擊不會啟動兩次。重遊保留已完成紀錄，沿用現有首次通關獎勵與重遊結算。
