# 本命法器常駐池與煉器碎片

狀態：常駐契器台已實作，獎池版本 `soulbound-v3-fragments20`；碎片規則 `forge-fragments-v1`。內部本命欄位仍為 `本命法寶`。

## 裝備與鍛造（2026-10-28）

- 背包與裝備合為「背包與裝備」單一分頁，上方只保留一格本命法器。築基、金丹及地圖入口共用同一畫面。
- 只有本命法器可裝配、提供被動效果與裝備戰力。舊的一般法器仍留在背包，可查看、分解或作為精煉輔材；不刪除既有持有資料。
- 八方煉器陣只接受含本命法器的組合（總共 2–8 件），只產出本命法器。原器取得途徑仍是契器台抽取／碎片兌換。前端計畫、舊打造入口、生成 API、已知配方領取及 D1 新配方登錄均套用限制。
- 更新前已付費但未含本命原器的工作不再產出一般法器，可點「退還舊煉製」，同一交易退還素材、必要印記及已付碎片／靈石並清除工作；管理員虛擬素材不額外發放。包含本命原器的舊工作繼續精煉。

## 抽取與保底

- 八種器型全部在同一個常駐池，沒有按器型拆池；每種仍有金丹到真仙的境界版本，共 64 件固定資料與八張 AI 圖。
- 金丹開放。每抽 2% 得到一件完整武器，其餘 98% 得到 20–40 個「煉器碎片」，21 種碎片數量均分機率。
- 若連續 19 抽未出完整武器，第 20 抽必出。任何一次出武器後，未中計數歸零；單抽、五連、升境界共用並保留進度。五連逐抽計算，可能在同批中觸發及重置保底。
- 武器結果中八種器型各 12.5%，保底也包含全部八種。抽中武器時 80% 為當前已解鎖品質、20% 為高一階；真仙維持真仙，不另設精選子池。
- 抽取仍用靈石：金丹每抽 500，每境加 100，真仙 1200。帳號首抽 250；首批金丹五連 2250，後續 2500。
- 普通煉器不能從無到有製造本命法器；原器可由常駐抽獎或碎片指定兌換取得，已持有原器可投入後續精煉。法器及其配方不可交易。
- 不再提供新操作的 30% 靈石回收。材料與普通／本命法器均走批次碎片分解。

## 常駐器型

| 器型 | 名稱 | 核心效果（金丹 → 真仙） |
| --- | --- | --- |
| 飛劍 | 逐風飛劍 | 原器連擊率 3% → 7.9%；精煉後依本命法寶供給上限 12% |
| 雷印 | 九霄雷印 | 反射實際生命傷害 6% → 14.4% |
| 靈珠 | 太初靈珠 | 命中吸血 4% → 11% |
| 星盤 | 七曜星盤 | 每連答三題的當次攻擊增傷 15% → 32.5%，答錯中斷 |
| 法鏡 | 澄心法鏡 | 答對攻擊後護盾 +25 → +81 |
| 古鐘 | 鎮岳古鐘 | 每次受傷固定減傷 12 → 47 |
| 靈幡 | 燎原靈幡 | 生命不高於 30% 時增傷 12% → 29.5% |
| 玄斧 | 破障玄斧 | 命中追加真實傷害 15 → 57 |

背包中的材料為圓形、普通法器為圓角方形；本命法器沿用普通法器的圓角方框、境界色與深色底，僅在上下左右各多一個小尖角。背包、裝備、物品詳情及分解背包共用同一輪廓。

合併分頁只保留本命法器空格，點擊後篩選已持有的對應法器，再點選法器直接裝配；未持有時留在裝備頁顯示空清單。物品詳情中的「前往契器台」才會切換至抽取分頁。

一般法寶改用圖標且停止自動生圖；只有本命法器保留圖片。八種常駐器型各有一張獨立 AI 圖，同名器型的境界版本共用該圖，品質以境界與光色區分。圖片與生成提示詞記錄在 `soulbound-art-prompts.json`。

已解鎖契器的玩家登入時，八種常駐器型圖片會優先於材料圖片預載；永久解鎖記錄仍有效，圖片不會因目前修為降低而失去預載優先順序。

每件另附基礎攻擊與生命：金丹 +25／+80，每境增加 +15／+45。每器只有一項主要特殊效果，允許跨丹性搭配，使用共用鬥法／團本引擎。星盤沿用戰鬥快照 `coreCorrectStreak`，沒有金丹也能累積。

## 本命法寶精煉

- 任一投入法寶為本命法寶，成品必定仍是本命法寶，以其器型、核心與原屬性為主，優先於其他素材的精煉深度、投入順序及煉器手法。沒有本命素材時禁止開始鍛造，不能憑空新造本命法寶。
- 多件本命素材先按精煉深度由深到淺，同深度按 ID 排序；第一件決定器型與核心，其餘提供相容特性。保留本命原屬性優先於新增輔材效果；原器的核心、攻擊、生命與第四個詞條不會因普通煉器的詞條數限制而被擠掉。成品最多四個不重複詞條；已滿四個時只提升原詞條，不新增或替換。
- 特殊屬性的生成上下限是同境界、同煉製階段、同素材數量、同管理員設定之普通法器範圍的1.2 倍。固定攻擊、百分比攻擊、固定生命、百分比生命及限時攻擊倍率沿用普通範圍；不是把模型產出的數字再乘 1.2。持續時間、每場一次及每題排除一項也不乘 1.2。
- 機率及減傷比例至多 100%；傷害上限屬於越小越強的屬性，生成範圍除以 1.2，最低可保存 約 4.17%。戰鬥原有的暴擊、吸血、反傷與疊加減傷總上限保留。
- 普通法器連擊供給仍至多 10%；本命法寶可提供至多 12%，與普通法器相加後法寶供給至多 12%，元嬰另計，最終連擊機率仍至多 75%。鬥法與團本使用相同規則，快照依裝備的正式欄位保存本命來源。
- 每次精煉的生命、攻擊與所有既有數值詞條都必須嚴格提升：固定值至少 +1，比例至少 +0.0001；單次傷害上限比例則至少下降 0.0001。比較基準為投入原器的正式數值，不先套境界範圍；提升保底可超出該次隨機生成範圍，但仍遵守既有法器供給上限。每場一次的無數值能力原樣保留。
- 若任何既有數值已達供給上限，或多件本命素材合計需要保留超過四種詞條，開始前即拒絕煉製，不扣材料或碎片。生成、AI 複核、已知配方重用與開爐存檔都核對逐項提升，防止資料正規化後倒退。
- 新成品保存 `soulboundRefinementVersion: 2`。不相容的舊配方不再攔截同組素材的新推演；舊物品與配方保留。已扣費且仍在進行的舊本命配方工作，開爐時使用新規則推演，不再扣素材或碎片；提交失敗可重試，成功後不可重領。

## 碎片指定兌換本命法器

- 契器台點擊目前境界的常駐法器可查看並用碎片指定兌換該器型，不改變原先八器同池隨機抽取機制。
- 金丹境開放，價格為金丹 600 碎片，往後每個境界增加 120；真仙依專屬身分判定。目前只兌換已解鎖境界的八種常駐原器，不會以碎片直接鑄造任意 AI 本命法器。
- 兌換由伺服器同一筆交易扣碎片、增加正式本命法器庫存並建立請求收據；相同請求重試不重複扣除或發放。兌換不影響抽數、未中累計、保底和靈石餘額，未確認抽取結果須先收入。

## 分解與碎片煉器

- 玩家碎片餘額獨立存為 `users/{uid}.forgeFragments`，預設 0，不放進會被其他答題流程整筆保存的 `stats`。
- 背包與煉器分頁均以獨立數量欄顯示持有煉器碎片，另設「物品分解」按鈕；煉器陣與配方的煉製按鈕顯示當次所需碎片，進行中的工作顯示已付費用。
- 背包與煉器分頁均有「物品分解」，介面為左右雙背包。點右側玩家背包物品會變暗並在左側待分解背包出現，點左側物品可移回，也可調整每項數量。左下角即時顯示可得煉器碎片與「確定分解」按鈕；檢視總清單後再按「確認分解」才扣除物品。
- 同次最多 100 種；數量必須為正整數。可以分解最後一件未裝備法器；裝備中的份數由伺服器保留。元嬰碎精、消耗道具與修煉物品不列入。
- 六種團本素材及兩種煉製印記都可分解。定價依伺服器固定材料目錄；法器依全站清單，常駐原器以固定池資料優先。前端提交的名稱、境界、單價不參與計算。
- 同境界的基礎煉器碎片費：凡人 6、煉氣 12、築基 24、金丹 42、元嬰 70、化神 110、煉虛 165、合體 235、渡劫 325、半仙 440、真仙 580。仍依原境界差與管理員基礎價調整，舊基礎靈石價按 10:1 換算，向上取整。
- 分解每件素材得同境界基礎費的 1/3（向下取整，至少 1）；普通法器得 1/2；本命法器得一份基礎費。例如金丹素材 +14、普通法器 +21、本命法器 +42。
- 新的已知／未知配方、二次／三次精煉與舊直接打造入口均扣碎片，不扣靈石。原有材料、配方、印記和耗時需求保留。碎片不足時不能開始。
- 新煉器工作記錄 `currency: forgeFragments`、`fragmentCost` 及 `goldCost: 0`。舊的已付靈石工作保持原進度，開爐不重新收費，畫面標示舊付款方式。

## 保存與重試

- `GET /api/soulbound` 回傳靈石、碎片、庫存、抽獎與兌換報價、未中計數與距 20 抽保底次數。
- `POST /api/soulbound/redeem` 帶 `requestId`、`itemId`、`poolVersion`、`expectedFragments`；依玩家當前境界核價，只核發現有常駐本命原器，交易收據可重試。
- `POST /api/soulbound/draw` 帶 `requestId`、`count`（1 或 5）、`poolVersion`、報價；抽數、保底、碎片／武器、靈石扣款與收據一次保存。舊版本未提交的抽取須重新同步。
- `POST /api/soulbound/ack` 確認混合結果；只有碎片的一批也可確認收入。關頁後仍能恢復結果。
- `GET /api/inventory/dismantle` 回傳目前可分解清單、裝備保留量、每件碎片及餘額。
- `POST /api/inventory/dismantle` 帶 `requestId`、`confirmed: true`、品項／數量及確認過的 `expectedFragments`。交易重新核對庫存與價值，整批刪除及加碎片共用一筆交易；任何一項不足則全部不變。
- 同一分解請求編號只執行一次，改換品項或數量會拒絕。不同分頁同時處理同一份庫存時，只有仍有足量庫存的操作能成功。
- 伺服器於 `inventoryDismantleReceipts` 保存收據；瀏覽器先保存待確認操作。回應中斷後以同一編號重試，不重新刪除或再發碎片。
- 所有 API 驗證主專案 A 的 ID token、撤銷狀態及來源。沿用既有資產權限模型，不新增寬鬆 Firestore 集合權限。

## 舊資料

舊法器、靈石、精煉工作與未確認批次保留。最早的純武器獎池每次抽取都已得到完整法器，因此從該版本轉換時新未中計數為 0，終身抽數不歸零。已完成的舊抽取／靈石回收收據仍可查回；新的靈石回收請求會引導使用碎片分解。

由五十抽碎片池升級為二十抽保底時，保留原連續未出武器進度；未滿 19 次者繼續累計，已達 19 次或以上者下一抽必出武器。金幣抽與票券抽共用同一計數。原已結算及未確認批次不重新抽取，舊請求收據重試仍回傳原結果。
