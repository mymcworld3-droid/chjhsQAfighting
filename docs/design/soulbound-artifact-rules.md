# 本命法器常駐契器台

狀態：**常駐契器台已實作**，固定獎池版本 `soulbound-v1`。內部仍使用 `本命法寶` 欄位，保留既有存檔。

## 取得與價格

- 金丹境（28 修為）開放，依永久解鎖的最高境界更新獎池，降低修為不會倒退。既有本命法器仍可調御、卸下及精煉。
- 八種器型各有金丹至真仙八種境界版本，共 64 件固定資料與八張 SVG 圖像。遠端全站清單不能移除或覆寫常駐原器。
- 單抽金丹 500 靈石，每升一境加 100，真仙 1200，作為首版測試值。帳號首抽 250；首次金丹五連 2250，後續 2500。
- 單抽與五連共用總抽數，每第五、十、十五次必得高一階。提早抽中高階不重置，升境界保留抽數。
- 一般 80% 當前境界、20% 高一階，各境界八種均分機率（各 10%／2.5%）；第五次高一階八種各 12.5%。
- 真仙池一般八種各 12.5%；每第五次為飛劍、靈珠、星盤、古鐘精選池，各 25%，不顯示不存在的境界。真仙身分由伺服器核對同學段五仙席位；半仙亦可抽中真仙品質法器。
- 每抽必得一件，收入寶庫，不自動裝備或消耗其他法器。
- 新本命法器僅能由靈石抽取取得。一般煉器、AI、已知配方不得從無到有產生，管理員提示不可例外。
- 本命法器及其配方不可交易。舊有市集委託不能買入，賣家仍可取消取回。

| 雷印 | 九霄雷印 | 反射實際生命傷害 6% → 14.4% |

每件另附基礎攻擊與生命：金丹 +25／+80，每境增加 +15／+45。每器只有一項主要特殊效果，允許跨丹性搭配，使用共用鬥法／團本引擎。星盤沿用戰鬥快照 `coreCorrectStreak`，沒有金丹也能累積。

## 操作

1. 「修煉 → 寶庫 → 裝備」的本命空格「締結本命」進入契器台；已裝備法器詳情提供「前往契器台」。
2. 顯示餘額、目前裝備及距保底次數；清單與機率可展開。
3. 單抽／五連標明總價，首次說明每抽必得、共享保底及保存方式。
4. 整批保存後播放約兩秒契印演出，可略過，尊重減少動態效果設定，高階加強光色及短音效。
5. 結果可逐件查看圖片、品質、核心能力及本命格基礎屬性差異。
6. 「調御此器」保留原裝備；「收入寶庫」確認本批；「再次抽取」先確認本批回到抽取按鈕，不直接扣下一批費用。

關閉視窗不視為確認。再次進入恢復未確認結果，確認前不能開始另一批，避免同時開啟的分頁掩蓋結果。

## 重複與精煉

- 重複物預設保留，可手動回收一件未裝備的重複原器，至少留一件；返還該抽實付價格的 30%，首抽為 75 靈石。
- 裝備中的一件預留，額外同款可回收。精煉器、既有非獎池器不提供回收，不自動轉換。
- 既有庫存是器型數量，沒有獨立實例。伺服器以器型與實付價格記錄數量，原器被精煉消耗時先移除較低價格紀錄，回收亦先用較低價格紀錄，並以現存未裝備的重複數量限制份數，不接受前端指定售價。
- 已有原器可卸下後投入八方煉器陣，用團本材料及第二／第三煉印記精煉。最深本命主材的成品繼承本命欄位與 `coreEffect`；裝備中的法器不能作素材。

## 保存與部署

- `GET /api/soulbound`：餘額、庫存、伺服器報價、保底、未確認批次、可回收原器。
- `POST /api/soulbound/draw`：`requestId`、`count`（只允許 1 或 5），伺服器用密碼學亂數抽取。
- `POST /api/soulbound/ack`：以原 `requestId` 確認當批結果。
- `POST /api/soulbound/recover`：`requestId`、`itemId`，庫存核對、回收及加款共用交易。
- 所有路由驗證主專案 A 的 Bearer ID token，交易同時保存餘額、入庫、抽數、價格紀錄及收據；重送同編號回傳原結果，不能更改操作內容。
- A 專案沿用 `users`、`worldImmortals`，新增 `soulboundDrawStates`、`soulboundDrawReceipts`，僅由 Admin SDK 讀寫。客戶端不需新增 Firestore 權限；維持未列舉集合預設拒絕，不使用允許所有集合寫入的 catch-all。
- 瀏覽器先保存待確認請求；斷線後「重試上次未確認的操作」沿用編號。未播放完的結果也由伺服器恢復，五連不會邊播放邊扣款。
- 本版沿用既有玩家餘額與庫存權限模型，不變更其他修煉或煉器存檔權限。

後續依每週靈石收入、抽取頻率及器型使用率調整價格與效果；願望法器暫留後續。
