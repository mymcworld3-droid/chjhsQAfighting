# 本命法寶取得與精煉規則

狀態：**取得規則已定案；靈石抽取入口與流程暫不實作。**

## 取得來源

- 玩法中的「本命法器」對應現有程式與存檔中的 `本命法寶` 裝備欄位；為保持相容，內部欄位名稱暫不更名。
- **新本命法寶僅可透過消耗靈石抽取獲得。** 一般煉器、AI 產物、已知配方與舊版煉製均不可從無到有產生本命法寶，管理員生成提示亦不可例外。
- **本階段不開發**抽獎入口、介面、抽取流程、機率、靈石價格、獎池或抽獎動畫；裝備格僅說明未來取得來源，不觸發任何抽取或扣款。
- 既有玩家持有的本命法寶與裝備狀態應保留；其他三種法寶仍可循既有途徑煉製。

## 二次／三次精煉

- 玩家**已持有**本命法寶，可先卸下原器，再投入八方煉器陣與其他材料或必要印記完成第二煉、第三煉。
- 以**既有本命法寶作為最深主材**精煉的裝備型成品繼承 `equipSlot = '本命法寶'`，AI 不能擅自改成其他裝備欄位。
- **沒有本命原器時不可藉由配方或生成機制煉製本命法寶。** 已裝備法寶不允許作為消耗素材。
- 精煉是對現存本命原器的再次鍛造，並非用普通材料代替抽取取得第一件本命法寶。

## 裝備格呈現

- 本命格使用單獨的暗金契印、紋章、圓形法陣、微光描邊；橫式與直式介面皆需可讀。
- 尚未裝備時顯示「本命待契」及「靈石抽取取得 · 尚未開放」；如果帳號已有可用的本命法寶，仍可點空格正常進入裝配流程。
- 已裝備時顯示既有法寶圖片、境界與戰力；點選仍可查看細節、卸下。
- **不提供假的抽獎按鈕。**

## 未來獨立開發（此版不做）
