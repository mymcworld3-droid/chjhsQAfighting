# 修煉分頁預覽

金丹、元神、煉器、契器、背包與裝備、狀態六個分頁共用墨綠卡片、暖金操作與一致的資訊層次。

- [手機版](mobile.webp)：390 × 844 外框，以正式直式遊戲比例呈現。
- [桌面版](desktop.webp)：1280 × 800 外框，以正式橫式遊戲比例呈現。

截圖透過實際頁面模組與既有圖像產生，角色「清風」及資源皆為獨立示範資料。煉器預覽已放入兩件素材，顯示可開始精煉的狀態。

檢查涵蓋六個分頁切換、金丹詳細與機率、元嬰節點與元神分支、手機兩件及八件選材、法器詳細關閉與輪播、背包篩選與物品詳細、狀態調御切換，以及返回修煉地圖。另以劍丹及元嬰初期、1024 × 768 尺寸檢查版面。
