# 單人武器副本：尖峰石域

適用分支：`main`。從底部「歷練」→「武器副本」開啟秘境選擇頁，再查看副本法則、掉落與難度，沿用問道試煉的答題充能、兩次出手、移動、雙武器、滑軌、動畫與結算。

## 難度與掉落

| 難度 | 靈獸階段（EXP 依既有規則） | 30% 掉落 | 20% 掉落 |
| --- | --- | --- | --- |
| 築基 | 5 | 築基劍類 | 煉氣劍類 |
| 金丹 | 10 | 金丹劍類 | 築基劍類 |
| 元嬰 | 20 | 元嬰劍類 | 金丹劍類 |
| 化神 | 35 | 化神劍類 | 元嬰劍類 |
| 合體 | 80 | 合體劍類 | 化神劍類 |
| 渡劫 | 110 | 渡劫劍類 | 合體劍類 |

共六階，沒有煉虛難度。初始只開放築基，每次通關僅解鎖下一階，可重打已通關難度。難度解鎖依伺服器確認的領主靈獸死亡結果，不必擊敗其餘守衛；不採信客戶端勝利、難度或解鎖旗標。

尖峰石域僅掉落劍類武器（`weaponType: sword`），圖騰不在當階或低一階掉落池內；其他武器取得途徑及圖騰傷害加成不變。

每次通關只擲一次 0–99 的獎勵亂數：0–29 當階、30–49 低一階、50–99 無武器；三者互斥，與一般試煉的未持有煉氣武器保底分開。低一階依六階副本順序（築基的低一階為煉氣；不含煉虛）。失敗、認輸及回合上限不抽武器。

武器沿用六種既有名稱、圖片、技能及 ID，每款只對應原生固定境界。掉落境界沒有武器池時，本次不掉落武器。重複武器自動增加一星精煉，最高五星；每星本武器招式傷害 +5%，超額數量保留。既有跨境界持有數量合併至原生境界，熟練度及技能等級不變。

## 副本券

- 初次領取三張；每天臺灣時間 00:00 補發三張，每日補發至五張，未用券保留；仙道任務獎勵可超過五張。
- 離線日數在下一次讀取或進場時由伺服器補算，補發上限仍為五張，不扣除超過上限的既有券，沒有客戶端可指定的領取時間。
- 每次新開挑戰消耗一張；收起、重新整理、重新連線與續戰不扣券；死亡或認輸不退券。
- 同一開始請求的識別碼重送，只回傳原房間，即使原房間已結束也不重扣。進行中不可改開其他難度。

## 地圖與戰鬥

- 種子產生 13×21 巖地，玩家由最下方進入。八隻基礎守衛，難度每升一階增加一隻，最多十三隻。
- 一隻 2×2 領主固定置於最深處，所有守衛均在其前方。領主開場即可行動並受到傷害、位移和擊退；**擊敗領主的當下立即通關**，無須清除剩餘守衛或額外作答。舊存檔仍使用討伐型目標也遵守此判定。
- 所有石域靈獸每回合最多移動一格，沒有突進、跳躍或擊退能力。守衛射程三格、領主四格，以曼哈頓距離量至最近的占位格。石柱不阻擋追蹤落石。
- 已開始蓄勢的預攻擊會隨玩家移動重新定位；退出射程後當次落點為空，結算不命中。回到射程內會重新追蹤；不在射程的未蓄勢靈獸需先移動、再開始新的蓄勢。
- 成功擊退（確實改變落點）會立即取消蓄勢，清空預攻擊格。玩家之後走回範圍也不能恢復被打斷的這次攻擊；下一個蓄勢週期才重新準備。撞牆、被其他單位擋住而未位移時不打斷。石域領主從開場起也可擊退，檢查完整 2×2 碰撞；其他原有首領的位移免疫維持原規則。
- 圖騰技能的攻擊傷害在此副本乘以 1.15，再沿用原傷害取整、護身與護盾流程；劍、普通攻擊與副本外傷害不加成。攻擊預覽同步顯示加成。
- 一般試煉及即時合作副本的靈獸在移動到位後重新判斷射程，能攻擊就立即準備攻擊，仍給玩家完整的預告／閃避時間。

## 資料與相容性

`GET /api/tactical/weapon-dungeons` 回傳券數、解鎖、各階通關次數與可續戰房間。`POST /api/tactical/start` 使用 `{activity:'weapon-dungeon',dungeonId:'peak-stone',difficulty:0..5,requestId}`；其他戰鬥、題目、審核與答題 API 沿用原路由。

戰鬥引擎的 `mode` 維持 `pve` 以共用答題流程，房間另有 `weaponDungeon` 欄位。玩家指標以 `roomIds['weapon-dungeon']` 與 `weaponDungeonV1` 保存，和 `roomIds.pve`、一般試煉種子及下一關進度分開。開始、扣券、房間保存及請求收據在同一交易；通關、解鎖、掉落、EXP 與 `rewarded` 也在同一交易完成，重送不重複發獎。

### 完整操作回歸

`npm run test:battle` 統一執行雙武器、修煉、戰棋、單人武器副本與合作副本的確定性測試。舊的三配置存檔相容測試仍驗證實際保存內容；新版對外狀態則依雙武器投影核對，不再要求已移除的第三個武器欄或顯示未解鎖招式。

`scripts/test-weapon-dungeons-browser.cjs` 使用獨立測試身分與簽章題目驗證入口、七種視窗大小、已鎖技能隱藏、兩次答題與解析、免費續戰、領主死亡（守衛仍存活）通關及下一階解鎖。`scripts/test-manual-training-browser.cjs` 驗證修煉彈窗、兩個裝備欄、圖片節點穩定與升級成果實際可點擊；原生 dialog 開啟時，成果容器必須位於同一 top layer，不能只靠外層 z-index 疊放。

雙武器裝備區在寬螢幕固定兩欄平分，手機窄螢幕改為單欄，避免沿用第三欄留下空白。滑軌拖曳仍會攔截該次手勢的合成 click，但下一次獨立按下會解除舊攔截，避免快速連續操作吞掉新點擊。

## 多秘境擴充

`WeaponDungeons.CATALOG` 提供副本識別碼、名稱、特色、戰術與加成；API 回傳 `dungeons` 陣列，各副本帶獨立難度與通關進度。票券全秘境共用，且一次只能進行一場。尖峰石域的原始 `unlocked/clears` 存檔保留，後續副本使用 `byDungeon`。新增可玩副本仍需配置對應地圖、敵人和戰鬥法則、主題 CSS；未實作秘境不可放入可玩目錄。新版石域有入口石障、交錯石門、領主區及種子鏡像變化。

橫式歷練頁以左側副本分類與右側秘境地圖呈現，預設選擇武器副本。地圖中的尖峰石域直接開啟其難度與掉落詳情，通關規則、票券及伺服器驗證不變。直式使用相同島嶼地圖，由歷練入口開啟；已停用的合作副本不顯示。

### 尖峰石域掉落類型調整（2026-11-27）

伺服器按秘境目錄的 `rewardWeaponType` 限制實際掉落與各秘境的預覽池；尖峰石域為 `sword`。舊房間缺少 ID 時仍採尖峰石域規則，未知秘境不發放武器。保留既有 30／20／50 區間、空池、精煉及圖騰加成；不回收歷史獎勵。新增六階所有亂數與候選劍款驗證，入口及實際結算瀏覽器斷言同步檢查。

### 掉落境界方向修正（2026-11-27）

20% 掉落改為比挑戰難度低一階，30% 當階及 50% 基礎無武器維持不變；高階空池不重抽。既有未結算房間也按當前規則重新推導掉落境界，不使用舊 nextRealm 快照；已發放的歷史獎勵不回收。難度解鎖仍向更高一階，不受掉落方向影響。
