# 問道試煉背景適性學習（第一版）

選定範圍的 AI 問道試煉會自動建立細觀念與考法清單，不另開教學模式或要求玩家填寫診斷表。隨機出題、檔案題庫、鬥法、團本與悟道試煉沿用既有流程。

## 產品規則與調整位置

共用規則位於 `public/cultivation/adaptive-learning-rules.js`。`POLICY` 定義診斷 5～8 題、同觀念連錯 2 題的講解門檻、10 次獨立作答至少答對 8 次的升級條件、挑戰所需的最少 5 次獨立作答。`MIX` 為每十題六補強、兩複習、兩挑戰；`REVIEW_DAYS` 為 1、3、7 天。這些是可修訂的產品起點，尚未以真實學習成效校準。

- 診斷題數按範圍的觀念數，在 5～8 題內決定。優先照顧未答過、未在待答佇列中的觀念；診斷結束並不代表所有項目已熟練。未練過的項目維持「待診斷」。
- 缺乏複習紀錄或穩定獨立答對的概念時，該次複習／挑戰改為補強。有到期紀錄先複習；尚未到期也可做已練項目的短期複習，但不提前推進間隔。
- 同一細觀念的兩種考法都答錯，也累計為該觀念連錯。穿插其他觀念不會清除這個連錯數。插入 AI 概念講解及含過程與答案的簡單示例；講解後優先生成同觀念的新情境。已經預取的待答題保留。AI 暫時不可用時，普通答題、題解與訂正照常，之後同觀念再嘗試補上講解。
- 完成、答對、獨立作答／答對、需要協助的次數分別記錄。成功收到且在作答前看到的助手提示算協助；純粹「檢查題目是否有誤」不算。作答前出現的概念講解也算協助；答完才看解析不回溯改寫那次作答。跳過不記為觀念答錯。
- 獨立表現達門檻逐級提高到中等、困難；近期失敗會降低難度。挑戰需至少五次獨立作答及穩定表現，加入應用與遷移情境；玩家手動選的難度始終是上限。
- 第一次獨立答對安排 1 天後複習；到期後再獨立答對，依次安排 3 天、7 天。到期前答對不提前升級；需要協助不視為獨立通過；答錯回到 1 天。
- 題卷上提供預設收合的「範圍學習足跡」，列出觀念、各考法、獨立／協助紀錄與複習日期。沿用綠色紙卷與安全數學排版。

## AI 分析與考法輪替

`adaptive-learning-api.cjs` 驗證主帳號，並以玩家已儲存的 focusedUnits 比對請求。科目、年級、範圍來自已存選擇，不信任額外送入的科目或難度。AI 分析只收到範圍與年級，講解只收到範圍和觀念，不收到帳號識別資料。

每範圍建立 2～16 個細觀念、最多 48 個具體考法。要求以位置、物理量、已知條件、求解目標或表示方式區分，不能只列「基本應用」「比較題」。鉛直圓面／圓周運動至少保留以下六項，每項有各自的考法和學習紀錄：

| 位置 | 速率 | 張力 |
| --- | --- | --- |
| 最高點 | 最高點速率 | 最高點張力 |
| 水平位置（中點） | 水平位置速率 | 水平位置張力 |
| 最低點 | 最低點速率 | 最低點張力 |

AI 可再補充範圍內的跨位置能量、反推、臨界條件等；題目必須明示繩／桿／軌道及阻力假設。AI 分析無法使用時，垂直圓周採上述暫定項目，其他範圍採三項暫定分類；介面明示為暫定，60 秒後可重試分析。有效 AI 清單存於伺服器專用 `adaptiveScopePlans`，同時請求共用一次分析，記憶體快取 24 小時，重啟可讀取已存清單。

同一批並行 API 取得不同細考法、各自的學習難度及題型任務。伺服器驗證任務、範圍、考法與難度綁定；只將通過既有格式、知識點、品質與近期重複檢查的候選題交付。備用池依帳號、範圍及清單版本隔離，重用時重新核對目前安排；暫時不適用的備用題保留到過期。近期考法與待答考法也用於避免連續重複。

## 記錄、重試與界線

細項紀錄位於自己的 `users.stats.adaptiveLearningV1`，與既有固定能力圖知識點分開。一般答題沿用既有客戶端判定答案與獎勵交易，在同筆交易合併最新學習紀錄；沒有增加新的獎勵來源。失敗的觀察寫入每帳號的瀏覽器待送佇列，重新連線／登入／下次取題時補送，使用事件 ID 去重；背景補送只更新適性紀錄。跨帳號、跨範圍的延遲講解不顯示，未答題及提示紀錄可隨原有題目快取復原。

每人最多保留 24 個近期範圍、每範圍 128 個最近事件 ID、8 個近期考法。待送佇列最多 64 筆；瀏覽器不允許儲存時只保留本次頁面的記憶體紀錄。清除瀏覽器資料前尚未送達的紀錄無法還原。

AI 的範圍清單與內容仍可能有遺漏或分類錯誤；欄位驗證不能證明內容一定符合目標。既有題解、問道助手與題目回報繼續提供核對管道。觀念狀態是作答紀錄的產品估計，不是能力量尺或對個人錯因的診斷。測試使用模擬 AI／資料，不代表已驗證學習成效。
