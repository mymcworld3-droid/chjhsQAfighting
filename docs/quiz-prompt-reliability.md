# Flash-Lite 出題提示詞核對

一般問道、悟道試煉、鬥法、團本與問鼎使用同一份正確性指令；機緣洞天保留自己的長文及解析格式，並共用條件、唯一性、一致性核對與本科檢查。

提示詞將正確性要求放在前面，按三件事核對：

1. 題幹有足夠條件、數據、單位及文本，沒有隱藏假設。
2. 先求解再設計選項，逐項驗證；每個錯誤選項都必須確實不成立，而非只是較不常見。
3. 以回代、單位、量級或文本依據核對，確保所問的量、正解、解析及取位一致。

科目檢查只加入當次科目需要的內容，例如數學的定義域與增根、英文的自然用法與唯一錯誤、化學的原子數與電荷。數學與英文各有一個已經過現有驗證器檢查的正確格式範例，明確要求不得抄題或改變指定範圍。洞天不加入這些獨立單題範例，避免干擾本文依據。

若無法核實，要求改出同範圍、同難度內可核對的題目。檢查過程不輸出給學生，解析仍維持精簡。保留降低後的難度與既有伺服器驗證；不改模型名稱、溫度、並行數或 API 呼叫次數。

這次驗證涵蓋範例正確性、十科檢查選擇、科目別名、提示詞順序與戰鬥提示長度。不代表已測得 Gemini 實際錯題率下降；尚未使用正式 API 做對照評測。

## 數值等式驗算

`numeric-calculation-guard.cjs` 在共用答案完整性檢查中驗算解析的數值等號鏈，不只比對 correct 與最後一句。例如兩邊都寫成 `√38`，但解析含有 `3^2+2(12)+5^2=9+24+25=38`，仍會因為相鄰數值等式不成立而退回整題，重寫題幹、正解、干擾選項與解析。

支援四則運算、括號、整數次方、TeX 分數、絕對值及明確分組的平方根。有理數採 BigInt 分數精確比較，無理平方根使用數值容差；字串長度、項數、巢狀深度、指數及數值大小均設上限，不執行輸入程式碼。純算式題幹也會使用完整運算式，避免只取多項相加的前兩項。

這個檢查沿用既有生成驗證入口：一般問道、適性問道、悟道、鬥法、問鼎及團本的並行候選，在勝出或加入備用池之前接受驗證；備用題取出時再次驗證。沿用共用完整性檢查的洞天題目也會檢查。驗算本身不增加模型請求；被退回的題目由既有重試流程重新生成。

只判斷可完整讀取的相鄰數值式；不刪去變數、單位或未知函數來猜答案。明確標示為錯誤示例、引述或近似取位的句子會跳過，無法解析的式子也不作數值判定。因此這能攔截已涵蓋的計算錯誤，仍不保證公式選用、題意、事實或所有數學推理正確。

回歸測試包含上述向量題、正確版本、運算優先順序、分數與小數、符號式不誤判、錯誤示例及惡意輸入；另以模擬供應商執行實際問道／戰鬥 handler，確認快速與延遲錯題均不得進入玩家回應或備用池，整批失敗時會重出完整題目。這不是正式模型錯題率的對照評測。
