# 體力戰棋與問道獵妖

分支：`stamina-battle`。基於 `main` 的 `aacf45f9`；只借用 `grid-world` 的點陣素材，未合併大世界功能。

## 入口與操作

- 首頁「問道試煉」按下後立即啟動既有全螢幕雲幕，在雲幕遮住畫面時載入目前關卡，直接進場；不顯示地形或分支選擇。既有任務入口也走相同流程。「鬥法論道」維持雙人配對入口。
- 問道試煉逐關推進，每關依種子決定 1～4 隻怪物，種類、生命、攻擊、移動速度與攻擊範圍可不同。怪物以紅格預告攻擊；移開即可避開，遠處怪物會先接近；每五關可遇鎮關守衛。
- 單人關卡隨機選取 7×7、9×7、11×9 戰場大小，搭配竹林、荒漠、雪嶺、庭苑或遺墟地形；石障、樹木、水域與出生點由種子生成。每次放置障礙後檢查地面連通性，確保敵我不被封死。雙人鬥法仍可選演武庭、青竹幽徑或古陣遺墟。
- 選「移動／攻擊／金丹技能」，點選目標地格，再確認操作。移動預覽顯示繞過障礙後的實際消耗。方向鍵也可選地格。
- 點「結束回合」才輪到敵人；答題本身不會自動攻擊。護身不耗體力，佔用一次攻擊／技能次數，減傷 40%。
- 通關彈窗直接提供「前往下一關」，失敗提供「重試本關」，兩者都沿用雲幕進場；不返回選地圖大廳。每關重新補滿生命並恢復初始體力。「收起」保留進度；「離開戰場」需確認認輸。重新整理後可回到同一關與未答題目；重試不重抽地形與敵人。

## 體力與勝負

| 項目 | 規則 |
| --- | --- |
| 初始／上限體力 | 2／10；未用完可留到下回合 |
| 答題 | 答對 +4，答錯 +1；每次自身回合最多兩題 |
| 移動 | 四向尋路，每格 1；緩速時下次移動每格 2 |
| 普攻 | 相鄰一格，消耗 2 |
| 金丹技能 | 消耗 3～4；施放後第二次自身回合才可再用 |
| 行動上限 | 每次自身回合兩次攻擊／技能，總操作最多 16 次 |
| 雙人鬥法 | 築基解鎖；按選定地圖配對，也可分享 16 碼戰場代碼 |
| 雙人行動時間 | 每人 120 秒；連續兩次自身回合逾時判負 |
| 勝利條件 | 擊倒所有敵方；總回合超過 60 時，PvP 比生命比例，PvE 判挑戰失敗 |

雙方題目依各自帳號已儲存的學制、範圍及難度簽發；答案與作答速度不決定先攻。每場角色數值、金丹及分支會固定，戰鬥中更換裝備不會重算。

## 九丹十八分支

| 金丹 | 分支一 | 分支二 |
| --- | --- | --- |
| 大海 | 逐浪：直線推擊 | 滄海：範圍緩速 |
| 太初 | 生息：回復生命 | 歸元：遠程吸血 |
| 凝心 | 凝障：護盾 | 靜念：遠程重擊 |
| 破境 | 斬關：低血斬殺 | 踏陣：躍進範圍攻擊 |
| 星辰 | 星隕：延遲範圍隕石 | 星軌：位移護盾 |
| 無垢 | 破妄：穿盾真傷 | 無塵：淨化回復 |
| 雷霆 | 奔雷：範圍雷擊 | 雷返：減傷反擊 |
| 陰陽 | 逆命：依已失生命增傷 | 陰陽：與敵人換位 |
| 劍心 | 劍遁：突進斬擊 | 萬劍：直線穿刺 |

未結丹玩家可使用調息護元。分支選擇維持在既有元神頁面，原本的兩條神通變化與升階方式不變，卡片和詳情會顯示對應戰場技能。元神選擇透過 `SPIRIT_BRANCHES` 對應戰場招式，進場自動採用已保存的變化；客戶端進場請求不能覆寫分支。舊版尚未覺醒元神的帳號沿用原已存 `tacticalPreferences` 或預設分支。

攻擊與生命沿用現有伺服器可信快照，包含境界、元嬰及裝備的攻擊／生命投影和開場護盾；對低境界對手繼續封印元嬰攻擊／生命加成。戰棋的金丹效果由上述主動技能提供，舊自動連擊、機率金丹技能及本命神通結算鏈沒有額外疊入戰棋；原團本及修煉規則保持各自的現行結算。

## 保存與獎勵

- 所有戰場 API 驗證既有主帳號登入票證；客戶端只送選項或地格，不能指定答題正誤、扣血、角色金丹、體力或獎勵。
- `tacticalBattleRooms` 與 `tacticalBattlePlayers` 只由伺服器存取。關卡種子、目前關數與最高通關數的權威進度放在後者的 `trial`；玩家文件的 `tacticalTrialV1` 只是顯示鏡像，不能用來指定或跳過關卡。沿用現有玩家 repository（含 D1 adapter），讓體力、答題紀錄與獎勵和玩家資料在同一事務寫入。不需要新增環境變數、資料搬遷或瀏覽器資料庫權限。
- 每個行動使用 request ID 及狀態 revision；答案綁定房間、參戰玩家、回合、題號。重送已提交的請求不重複扣體力、答題計數或發獎。
- 答題前的快照刪除正解與解析；生成中的延遲回應若已跨回合會被拒絕。出題繼續通過 `/api/generate-quiz` 的學制、格式、品質、知識點及重複題驗證。
- 問道答對沿用境界靈石公式及元嬰修為分支；金丹期後答錯扣一修為。更新固定知識點、舊知識圖譜、連答數、問道任務與 `exam_logs`。
- PvE 第 n 關通關額外獲得 `35 + min(100, (n-1)×5)` 靈石及 2＋元嬰分支修為；至少答對一題才可領取額外獎勵。清除敵人後，下一關與最高通關數同一事務更新；重送通關不重複前進。PvP 勝利 500 靈石及 5＋元嬰分支修為，落敗 200，平手 250 及 2 修為；雙方合計至少完成兩題才算正式結算及鬥法任務。
- 通關獎勵、雙方任務計數與房間結束標記同一事務提交。重整、斷線重送及同時結算均不重複發獎。伺服器回傳自己帳號的最新進度，畫面立即更新。
- 僅在等待配對或對手回合時輪詢，背景分頁暫停；單人場及自己的正常行動時間不輪詢。連線失敗採退避；停用舊問道題目預載及舊鬥法監聽，避免雙套流程同時耗用。

## 驗證

```bash
node --test tests/tactical-combat.test.cjs
npm run build:module-versions
npm test
npm run check:module-versions
node scripts/test-tactical-browser.cjs
```

瀏覽器測試需要可用的 Playwright 與 Chromium；可用 `TACTICAL_CHROMIUM` 指定執行檔，`TACTICAL_FONT_DIR` 指定本機 `@fontsource/noto-sans-tc` 目錄供測試截圖使用。測試伺服器只綁定 localhost，使用記憶體資料與假身分，不連接正式帳號／AI／資料庫。

規則測試另涵蓋 80 個關卡的穩定生成與連通性、通關只前進一次、並行進場接續同一關、失敗不重抽，以及九丹全部元神變化的技能對應。瀏覽器直接載入正式雲幕實作，涵蓋按下即進場、進場全程沒有選擇畫面、下一關、手機直式／橫式、答題加體力、移動回應遺失後自動重試、重新整理續關、雙人配對與換手同步。正式雲端 AI 出題及正式 D1 延遲仍需在此分支的部署環境驗收。
