# 化神本命神通

修為達化神（188，已保存的永久境界解鎖亦有效）後，修煉的「元嬰」分頁轉為「元神」，原元嬰分支保留，上方新增本命神通。依**已調御**金丹丹性提供兩種變化，只能同時啟用一種；洗髓候選金丹不影響神通，停用金丹時神通一起停用。

## 覺醒與十階養成

- 首次選擇該丹性的變化，免費覺醒一階。二至十階各消耗目標階數個元嬰碎精，依序為 2、3、4、5、6、7、8、9、10，合計 54，不再乘二。
- 同丹性兩種變化共用已修習階數，免費切換，不會同時疊加兩種效果。
- 各丹性進度分別保存；改丹不退還神通材料，換回原丹恢復原進度。金丹品級不影響神通階數與倍率。
- 元嬰重修不清除神通，神通升階不清除元嬰分支。沿用元嬰碎精取得方式，未新增材料、定時資料同步或戰鬥外計數寫入。
- 養成持久化欄位：`innateAbilityGrowth = {version:1, paths:{[coreType]:{branch,level}}}`。保存與材料扣除在同一筆玩家資料交易中完成，失敗不先改本機資料。

## 各丹性變化

以下數值為十階；中間階數按 `public/cultivation/innate-ability.js` 的逐階預覽計算。普通追加傷害以當場攻擊力（最多 600）計算，獨立命中並受防禦、法寶護盾與保命影響，不再次觸發法寶攻擊、爆擊或連擊。

「累積答對」不要求連答，答錯不清空累計；「連續答對」在答錯後重新計算。所有計數自新的一場戰鬥開始，切換神通不影響已在進行中的戰鬥快照。回血不超過生命上限，也不使已陣亡玩家復活。既有金丹期後答錯扣修為規則不變。

太初生息每階回復生命上限 0.5%，靜心返照每階 0.6%，歸元納氣每階轉化實際回血量的 3%，破妄斬關每階將元嬰斬殺門檻增加 2 個百分點。破妄斬關改變既有元嬰斬殺的觸發範圍，不再另外供應原先的 25% 攻擊力追擊；三疊破障十階倍率由 75% 降至 60%；三星聚曜十階隕石倍率由 90% 降至 60%。

歸元納氣計入金丹、元嬰吸血及法寶治療實際補回的生命，滿血溢補不計。轉化真傷穿過道心護體，法寶護盾、傷害上限及保命仍有效；不再產生吸血、反擊、連擊或二次治療轉傷。敵方已陣亡時不追加轉化傷害。團本受擊後反擊吸血的轉傷與原反擊分開記錄，傷害與勝負隨同一筆伺服器結算生效。

能量球與三重屏障光束在鬥法與團本共用 `innate-ability-effects.js`。特效只讀取結算標記，以角色實際位置決定射線，按毫秒時間播放；重繪不重複結算，離場與播放結束清理特效，減少動態偏好省略匯聚粒子。

元嬰星隕依三題內答對數逐顆落下；三星聚曜再追加一顆，三題全對時最多四顆。每顆各自取整、消耗道心護體、計算法寶防禦及反擊，致命後停止後續隕石。團本以同一筆權威結算保存逐顆血量快照，前端按每顆 900 毫秒依序播放命中、扣血與音效，不為動畫增加網路寫入。大海、劍心、歸元納氣、三疊破障及星隕的實際命中提供短促震屏，減少動態偏好不震屏。

無塵神光以護體擋下的普通入射傷害（含攻擊者增傷／爆擊）計算，排除穿透護體的真傷；其回敬真傷不引發吸血或再次反傷。洗心明性每階回復生命上限 0.6%，陰陽相生每階回復已損失生命 1%，劍意歸一每階回復已損失生命的 0.5%，無塵神光每階轉化吸收量 1%。

陰陽兩種變化於生命不高於 50% 時，額外減少所受普通傷害，每階 2.5 個百分點（十階 25%）；真實傷害不受此減傷影響。逆命回天額外低血追加傷害每階由 3% 提升至 8%，十階由 30% 提升至 80%，與金丹本身的效果分別結算。劍意歸一的治療基數由生命上限改為已損失生命，滿血時回血為零。

## 鬥法封印與團本

- 對手目前修為 <68（即金丹期及以下）時，本命神通**完整封印**，包括傷害、真傷、回血、吸血、反擊與計數；對手達元嬰即可生效，不要求對手也達化神。雙方各自判斷。
- 封印不依賴元嬰快照是否存在；配對套用一次，逐回合結算再次檢查，介面顯示「神通封印」。
- 鬥法只從房間快照推進一次作答計數；重試同一結算不修改原始輸入，進度隨既有回合交易保存。舊房間沒有神通欄位則無新效果。
- 團本由伺服器從已保存的玩家資料建立神通快照，沿用既有 action ID 去重與結算交易。劫雷返照只作用於答對後下一次首領攻擊，格擋也消耗窗口；首領攻擊不修改上一題答對／答錯的學習歷史。
- 戰鬥神通目前作用於鬥法與團本，不額外提高一般問道、閉關或機緣洞天修為獎勵。
