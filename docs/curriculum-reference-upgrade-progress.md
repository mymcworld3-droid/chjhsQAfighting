### 已發現的具體缺漏

1. `數學/高中二年級/空間向量內積.json` 只有兩題，至少需新增三道不同考法的題目。此題庫與平面向量題庫保持分離。
2. 高三「圓錐曲線及其方程式」和「橢圓、雙曲線、拋物線的性質」各有一道相同的 `y²=8x` 焦點題。盤點保守地不將這兩道計入結構候選題，各庫暫以四道計數；如何替換或改為共用觀念，留待標準觀念與內容審核處理。
3. 英文有兩道題幹同為 `Choose the grammatically correct sentence.`，但選項與答案考查不同文法。列待複核，**沒有自動當作重複題淘汰**。
4. 目前沒有失效索引、未索引參考題檔或重複參考題 ID。題目正解、條件、干擾選項、近似題與教材深度仍需獨立內容審核。
5. 國中所有年級共用相同科目選單。七年級物理／化學／地科、八年級生物／地科、九年級生物／化學沒有可選章節；第 4 階段應依年級實際資料調整選項。

## 開發命令與計數決策

```sh
npm run audit:curriculum
npm run check:curriculum-inventory
node --test tests/curriculum-inventory.test.cjs
```

盤點程式只按同年級、同課程分流的 NFKC／空白正規化名稱建立候選鍵；題庫查找保留原系統的數學共同索引。沒有自行把「投影」「內積」「空間向量」等相近內容合併。標準觀念 ID 全留 null；正式建立時須逐一確認學習深度。

`--check` 檢查報告是否過期，並不表示教材已達正式開放標準；已知題數不足與重複問題會保留在報告。開發者可用 `node scripts/audit-curriculum-inventory.cjs --check --strict` 將結構問題視為失敗；目前存在已知重複題，不能宣稱 strict 已通過。第 5 階段再建立完整的教材／標準觀念／內容審核資格門檻。

待補題數按現行細項字串與精確映射估計。完成同義名稱確認後可能減少，內容審核剔除錯題或限制某些技能不適合單選評量後，也會改變，不能直接據此大量生成湊數。
