- 翰林數學 A／B 分開，上冊為115學年度、下冊為114學年度；不冒稱同一年版本。A冊的三角公式及空間向量不可直接搬入B冊。
- 翰林物理I、III使用115學年度來源，II、IV、V使用114學年度來源；化學I–V使用115學年度來源。
- 龍騰官方頁未標學年度，保留未知；數學3A／3B只公開單元層級，沒有憑空補成節次目次。4A／4B、物理V、化學V沒有公開完整目次，保留書籍資料並禁止選用。
- 物理、化學選修I–V的教學年級與學期依學校安排。入口先放在使用者要求的高二，冊次獨立選擇；這不表示各校高二全部教授五冊。
- 資料只記目次名稱、來源、查證日期與實際年份。實驗操作不被直接轉成單選題；公開活動名稱另存於來源資料。
- 三民、泰宇、南一等其他出版社的高二三科尚未完成本輪逐冊來源查證，沒有複製翰林或龍騰內容來冒充。
