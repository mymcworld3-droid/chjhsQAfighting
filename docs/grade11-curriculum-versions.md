## 來源層級與適用年份

- 25冊採用出版社公開原始目次，選單依原資料保存學年度；官方頁未標年份時保留未知。
- 59冊依[升學王公開版本對照表](https://www.go100.com.tw/108_comparison_table.php)整理。選單與章節卡明示「課程對照」，不冒稱出版社原始目次。此來源可補足南一、三民、全華、泰宇及原龍騰四冊的範圍缺口。
- 課程對照只採各出版社自己的左欄，沒有把右欄三貝德課程當成該出版社節次。每冊保存來源網址、頁碼、標示學年度、表頭及原PDF的SHA-256，供日後核對。
- 對照表上學期及III／V冊多標115，下學期II／IV及數學4A／4B檔標114；選單保留來源標示，不將114改稱115。對照年份不是已核驗的出版社版次。
- 南一數學3A採115對照表的十節，沒有沿用113年只有八節的舊安排；3B保留「2-1對數、2-2指數與對數函數」，4B的矩陣章在條件機率章前。A／B不互相補造節次。
- 南一化學V對照表的「有機酸與脂」正規化為「有機酸與酯」，原字及修正理由保留在該冊normalizationNotes。其他分頁造成的斷行只去除空白；沒有借用右欄補章節。
- 泰宇目前只有化學I產品頁公開完整章節，其餘產品頁雖有書籍資料，章節欄為空，故其餘13冊採課程對照，不宣稱全部為官方原始目次。

## 執行與相容性

既有複習版、自訂範圍、學習紀錄及分享碼保留。新範圍保存冊次、年份與出版社，伺服器核對細項確實屬於所選書目；換冊、換版本不沿用其他版本的備題。按年級／科目延遲載入，不讓客戶端掃描參考題檔。

`scopeSelectionStatus`分為`verified-toc`與`verified-crosswalk`；兩者均可選範圍。原27階段計畫的整冊參考題資格另以`releaseStatus`保存，本輪依使用者明確指示不執行該部分。既有AI出題與審核流程不因本輪資料補全而停用。

`curriculum-data/grade11-coverage-targets.json`記錄本輪已確認的六家出版社×十四冊。覆蓋率稽核逐一核對84項，漏冊或未具來源資格的冊次會使檢查失敗。逐冊JSON保留各自來源，不複製其他出版社章節來湊數。

驗證結果見 [進度紀錄](curriculum-reference-upgrade-progress.md)。
