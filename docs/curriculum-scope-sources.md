# 課程範圍資料：來源、適用程度與維護方式

## 本次更新（2026-09-22）

- 洞府「專注練習」目前改為 **年級 → 科目 → 章節或考點**。第一、第二學期在章節頁合併顯示，章節旁保留原學期標記；不再要求玩家另選學期或「複習版／出版社版本」。
- 沿用既有 `gameSettings.focusedUnits` 形式（`path`、`detail`、`sub_topics`），避免更動玩家既有資料與出題 API。
- 修正 `civics.json` 與 `science.json` 原有 JSON 格式問題；校訂 **康軒 115 學年度國中數學七上**的章節與 1-1～3-3 順序。
- 其餘內建國中各出版社的 JSON **仍屬複習重點整理，並未完成逐版、逐冊、逐學年度正式目次核對**，介面必須保留提示，勿稱為官方目錄。英文資料按核心語法及版本情境分類，也不等同正式逐課目次。
- 國小及高中已接入下述整理版及部分章節對照，未核對冊次不得冒用其他版本。

## 下一批資料格式

底層資料仍可保持：`學科 > 年級 > 學期 > 版本 > [{ "unit": "章名", "details": ["節名／考點"] }]`，但前端不再把學期與版本當成玩家必選步驟。若資料有 `108課綱複習版`，合併頁優先使用該整理；沒有複習版時使用既有預設資料來源，再把兩學期章節合併。正式校訂時另記學年度與來源連結，未查到者標為「整理版」。不要從其他出版社複製同名章節假裝已查證，亦不要把課本原文或試題內容整批複製到專案。

提醒：目前單人練習仍由 AI 生成題目；單元選擇只能約束提示，無法完全保證每道題目不超出指定範圍。正式版仍應加上題目內容的出題後驗證。


## 2026-09-22：普通型高中範圍擴充

**已接入洞府專注練習（非僅範例）**：高一～高三，第一、第二學期，國文、英文、數學、高二數學 A／B、高三數學甲／乙、物理、化學、生物、地球科學、歷史、地理、公民、資訊科技。新資料位於 `public/high_school_unit_name/core.json` 與 `humanities.json`。

- 一般課程以「108課綱複習版」標明：此為按領域課綱與選修課程整理的**複習地圖**，不是逐出版社、逐學年度目次；選修課開設年級、學期會因學校而異。
- 高一第一學期數學另有「翰林版（108課綱初版）」、「三民版（108課綱初版）」、「泰宇版（108課綱初版）」，按下列目錄對照的章節與節名整理。其餘出版社及冊次沒有獨立核對目次，**不得呈現為已核對的出版社版**。
- 高二數學 A 與 B、高三數學甲與乙獨立選擇；儲存時採 `數學/高中二年級/第一學期/數學A/108課綱複習版` 等路徑，出題學科仍標為數學，提示詞附分流及年級。
- 仍可加入跨科／跨年級主題與手動自訂範圍，保留舊有 `focusedUnits` 格式。原本勾選單元上限為 24，尚未調整戰鬥端上限。
- 仍有未完成項目：逐年驗證所有出版社完整目次；根據使用者持有之課本核對選修冊次；AI 題目的出題後課綱範圍驗證。複習地圖不能保證每題完全相符。

## 2026-09-22：國小一至六年級單元選擇擴充

新增 `public/elementary_school_unit_name/math.json`、`core.json` 與 `other.json`，在既有「洞府 → 範圍設定 → 專注練習」支援國小一年級至六年級、上下學期、可複選的單元與細項，也支援跨科目及自訂主題。保留既有 `gameSettings.focusedUnits` 格式，不需搬遷舊資料。

| 年級 | 目前有系統整理的科目 |
| --- | --- |
| 一、二年級 | 國語、數學、生活、健康與體育、本土語文（共通主題） |
| 三至六年級 | 國語、英文、數學、自然科學、社會、藝術、綜合活動、健康與體育、本土語文（共通主題） |

**重要：**科目單元的「108課綱複習版」為符合學習階段的複習地圖，不是出版社逐課完整目次。數學一至六年級第一學期另提供南一、翰林、康軒各前三單元「類××版（目錄節錄）」供快速定位；**只有前三單元**，不是完整教材，亦不可推論適用 115 學年度。二至六年級各版本可能對應不同學年度；五年級資料標示 113 學年度，六年級參考來源提及 114/115 年度混用。未查證的冊次僅提供一般複習地圖。

國小一、二年級以「生活」整合相關自然、社會與藝術活動；三至六年級才拆成自然科學、社會、藝術與綜合活動的單獨選單。英語文三年級起提供正式課程複習主題；低年級校訂英語須用自訂主題。本土語文各校及學生可能選修閩南語、客語、原住民族語等不同語別，目前僅提供共通主題；字音與拼寫問題應明確指定所學語別，不可任意混題。健康與體育中的運動技能較適合實際操作，不宜以單選題取代技能評量。

## 2026-09-25：選課流程簡化

- 可見流程由五步縮為三步：**年級 → 科目 → 章節與考點**。
- 選完科目立即進入章節頁，不再顯示「學期／冊次」與「版本」選擇頁。
- 第一、第二學期單元同頁呈現，使用「上學期／下學期」標籤辨識來源。
- 儲存到 `focusedUnits` 時改用「全學年」路徑；既有舊格式資料仍可繼續出題，不需搬移。
