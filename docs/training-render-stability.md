# 修煉頁渲染與重載診斷

修煉導覽使用同步站內切換與平移，不再重用啟動雲幕及其兩張全畫面圖片；點擊場景內建築仍保留雲幕。導覽不呼叫 `location.reload()`，也不重設遊戲 iframe 網址。本機使用真實修煉模組的測試帳號資料替身測試時，未重現使用者回報的整份文件重載，因此不能把轉場效果或 GPU 負載當成已確認根因。

建築光暈改為單一窄幅陰影，不再同時繪製大範圍模糊副本與多道陰影，減少進場時的中介渲染表面。仍保留原圖、點擊區域、解鎖與動畫時長。

`training-render-guard.js` 在同一分頁的 sessionStorage 記錄短期進場狀態，只保存時間與渲染狀態，不含帳號資料。若進場 60 秒內文件消失，而且沒有正常 `pagehide` 或完成進場的紀錄，下次進場改用既有完整背景與相同建築按鈕，略過額外雲層表面。這是異常中斷的恢復措施，不宣稱一定是記憶體崩潰。

正常重新整理／離站會留下 `pagehide`，不會因此啟動降載。原畫面穩定 15 秒或正常切離後清除進場標記；降載模式在該分頁內保留，以避免重複中斷。新分頁恢復一般渲染。

開發者可呼叫 `window.getTrainingRenderDiagnostics()` 查看 `profile`、`interruptedEntry`、Navigation Timing 類型與 `document.wasDiscarded`。此紀錄不改變登入狀態、題目、背包、修為或任何伺服器資料。
