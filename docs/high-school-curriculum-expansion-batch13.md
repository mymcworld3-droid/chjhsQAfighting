# 第十三批：南一國文第五冊與第三冊自學

新增第五冊11課及1自學單元、36個編輯性考點；第三冊新增1自學單元、3個考點。南一五冊共61個單元、183個考點。

## 來源限制
第五冊取110學年度與聲稱115學年度的第三方公開檔名清單搜尋索引，所列篇名與順序相同；兩清單可能同源。未取得出版社原始目次、正式課本、學年度及節錄原文，不將兩個轉載當作兩份獨立出版社證據。只使用篇名與順序，沒有取得、下載或轉錄教材檔案內容。第三冊「用奇謀孔明借箭」同樣以第三方早期檔名索引作為補充來源，保留原評量回次。第五冊採獨立來源資格與畫面標示，schoolYear保留null。學習範圍可用，不等於正式教材釋出或參考題審核。

來源網址記錄於資料檔 sources，供後續向出版社或學校確認。國教院審定資料僅證實有南一第五冊及奇異果第五冊，不代表目次完整。奇異果第五冊及翰林英文部分課次仍未取得足夠資料。

題庫沒有改動。前後端讀取南一分片擴至高三，新增資格限制與全冊分享往返測試，維持原有範圍相容性。
