# 機緣洞天

機緣洞天是一篇與目前修習範圍相應的原創長文，固定五題共用本文，不限時。
每題技能依序為資訊擷取、整合比較、推論理解、情境應用、評估判斷。

## 遭遇與範圍

- 只在一般問道已作答後按「下一題」計數，答對、答錯皆可；切頁、連點、洞天內下一題不計數。
- 每輪在 20～30（含兩端）題間均勻抽出一次間隔；完成並按「下一題」達到該題數，就開始下一次機緣。平均間隔 25 題。
- 首次也至少完成二十題才遭遇；遇見成功或主動略過載入時抽出下一輪間隔。機緣內五題不計入問道間隔。
- 已保存的舊間隔若少於 20 題，重設為 20～30 題的新倒數；原本已在 20～30 題內的間隔保留進度。
- 倒數按帳號保存於瀏覽器，重新整理、切頁或更換修習範圍不清空進度；文章仍使用觸發當下的範圍。各帳號分別計數，瀏覽器停用儲存時保留本次頁面內計數。
- 連點由單次題目鎖與下一題忙碌鎖阻擋。若生成或連線失敗，保留到期狀態，在下一個已作答的問道題目再嘗試，不重新抽掉玩家累積的進度。
- 伺服器已建立機緣、頁面尚未收到回應便中斷時，恢復既有機緣會補上下一輪倒數；反覆恢復不重抽。
- 專注練習採 focusedUnits，綜合自訂採 comprehensiveUnits，題庫採 source。選定年級優先於個人程度。
- 未自訂範圍的綜合練習，才從該年級科目抽取；專注範圍無效時不擅自改為綜合。
- 多個單元依最近 12 篇同單元出現次數加權，較少出現者權重較高；不跨出已儲存範圍。
- 延伸練習、教程、五仙挑戰、其他洞天不插入機緣。

## 文本品質

伺服器從玩家已儲存的 gameSettings 取得範圍，不接受客戶端指定題目或答案。
國小至少 400 字、國中至少 650 字、高中以上至少 850 字；英文至少 900 個非空白字元。
正文四至十段，每段編為 P1、P2……；不得重複段落充字數。
必須恰好五題、指定技能順序、四個不同選項、完整解析、具體考點。
每題的引文必須逐字存在於指定段落；整合與評估題至少引用兩段。
第二次獨立 AI 複核重新解題，核對範圍、文章、唯一正解、跨題洩題與解析；失敗最多重建一次。
品質未通過、連線失敗或範圍變動時，保留一般問道尚未作答題目並回到問道。

相同範圍共用生成請求，最多三個不同範圍同時生成；範圍快取最多 64 篇、八小時有效。
玩家最近 24 篇文本不得重複，已參悟或主動結束的文本都會進入此歷史。
單帳號每小時最多八次開始，生成嘗試最多十二次；這是防止大量 AI 請求的保護，並非每日入場券。

## 作答、恢復與結算

API 位於 `/api/opportunity/{current,start,answer,settle,abandon,report}`。
所有 API 均驗證 Firebase 主專案 A 身分。本文、選项順序、逐題作答與結算記錄由伺服器保存。
未作答的答案與解析不傳到瀏覽器；重送相同作答回傳原結果，不能換答案、跳題或跨帳號作答。
重新整理可恢復尚未結束的機緣，保留二十四小時。暫離保留進度，主動結束不給通關獎勵。
長文可隨時查閱，解析的引文按鈕會定位段落。桌面左右對照，手機上下排列，上方固定按鈕可切换本文與題目；下一題直接定位題目，不必重新捲過全文。
五題完成後可回顧本文與全部解析。

通關給 50 + 20 × 答對數靈石、答對數修為；元嬰玩家另給答對數神識，並沿用已裝備金丹的洞天修為節點加成。
獎勵與機緣完成狀態在主專案 A 同一筆交易寫入，重送或同時結算只入帳一次；也計入洞天任務進度。
資料集合：`opportunityRuns`、`opportunityStates`、`opportunityReports`。這些集合只需伺服器存取，不應開放客戶端寫入。
題目回報會保存本文、題目、原文依據與具體原因，重送同一題回報更新同一筆紀錄；目前為待檢查佇列，不會自動改題或發出補償。

## 驗證

`node --test tests/opportunity-dongtian.test.cjs` 驗證範圍、長文與引文品質、複核重建、生成共享、答案保密、逐題重送、範圍變動、暫離、帳號隔離與並行結算。
修改前端後執行 `npm run build:module-versions`，完整驗證使用 `npm test` 及 `npm run check:module-versions`。
