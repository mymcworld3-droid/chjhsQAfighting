# 元嬰丹性能力與平衡

左側凌霄／追擊／終極節點分別提供能力進度的 30%／20%／50%，沿用原節點與神識價格，不刪配點。
原先終極固定傷害改為本命能力；攻擊、生命與學習分支保留。右側終極回復統一每級 12–20（九品至一品），避免某丹性同時具有更高輸出與額外生存優勢。

| 丹性 | 左側主能力 |
| --- | --- |
| 滄海 | 高生命目標蓄潮爆發 |
| 太初 | 實際命中後吸血 |
| 凝心 | 固定種子 25% 會心 |
| 破境 | 低生命目標斬殺 |
| 星辰 | 每連答三題星隕，答錯中斷 |
| 無垢 | 固定真傷，穿透道心護體與普通減傷 |
| 雷霆 | 直接受傷後反傷，不反射反傷 |
| 陰陽 | 自身低生命時增傷 |
| 劍心 | 首擊之後獨立追擊，可接在護體擋下的首擊後 |

無垢真傷各節點每級基數為 2／1／3，品級倍率 1–1.2；完整配點提供 60–72，結算不套用「80 點上限」。法寶真傷數值不變；法寶護盾及保命仍處理元嬰真傷。
普通丹性能力以 28%–32% 的進度倍率為基礎，再依各種觸發條件與收益係數結算。能力攻擊基準最高取 600，追加傷害不再被法寶暴擊、連擊放大，追擊不再次觸發法寶攻擊效果。吸血不能從被擋或溢出傷害獲利。

凝心修習丹性能力後，每連答至少三題才可再凝聚護體，避免連答門檻後每題護體；雷霆修習後，金丹雷劫反擊倍率為實際受傷的 25%，另外結算元嬰雷返。尚未修習與金丹以下鬥法維持原有規則。所有元嬰能力在對手境界為金丹以下時停用。

## 可重現平衡檢查

`tests/soul-talent-balance.test.cjs` 使用完整實際鬥法引擎與伺服器角色快照。九丹兩兩對戰，每組 200 場，分別測九品與一品，合計 14,400 場；相同基礎攻擊 200、生命 1000、全樹十級、無法寶、答對率 80%、首答機會各半，15 回合上限，確定種子可重播。

| 丹性 | 九品勝率（約） | 一品勝率（約） |
| --- | ---: | ---: |
| 滄海 | 52% | 50% |
| 太初 | 50% | 41% |
| 凝心 | 54% | 53% |
| 破境 | 51% | 41% |
| 星辰 | 48% | 46% |
| 無垢 | 42% | 57% |
| 雷霆 | 50% | 61% |
| 陰陽 | 50% | 46% |
| 劍心 | 52% | 54% |

測試要求各丹性平均勝率介於 35%–65%，用來阻止明顯的數值回歸。此為固定情境的工程檢查，不能代表所有裝備組合、答題速度、部分配點或真人策略；正式營運仍需觀察各丹性的實際對戰資料。
