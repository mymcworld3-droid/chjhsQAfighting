# 元嬰丹性能力與平衡

左側凌霄／追擊／終極節點分別提供能力進度的 30%／20%／50%，沿用原節點與神識價格，不刪配點。
原先終極固定傷害改為本命能力；攻擊、生命與學習分支保留。右側終極回復統一每級 12–20（九品至一品），避免某丹性同時具有更高輸出與額外生存優勢。

| 丹性 | 左側主能力 |
| --- | --- |
| 滄海 | 高生命目標蓄潮爆發 |
| 太初 | 實際命中後吸血 |
| 凝心 | 固定種子 25% 會心 |
| 破境 | 低生命目標斬殺 |
| 星辰 | 每作答三題結算星隕，傷害＝該三題答對數 × 攻擊力 × 元嬰能力係數 × 1.5，答錯也計入作答 |
| 無垢 | 固定真傷，穿透道心護體與普通減傷 |
| 雷霆 | 金丹受擊按品級 10%–90% 機率使當次共用反擊率 +75 個百分點，與法寶、元嬰反擊率相加，例如法寶 16% 觸發後為 91%。真傷不計入基數，不反射反傷 |
| 陰陽 | 自身低生命時增傷 |
| 劍心 | 首擊之後獨立追擊，可接在護體擋下的首擊後 |

無垢真傷各節點每級基數為 2／1／3，品級倍率 1–1.2；完整配點提供 60–72，結算不套用「80 點上限」。法寶真傷數值不變；法寶護盾及保命仍處理元嬰真傷。
普通丹性能力以 28%–32% 的進度倍率為基礎，再依各種觸發條件與收益係數結算。能力攻擊基準最高取 600，追加傷害不再被法寶暴擊、連擊放大，追擊不再次觸發法寶攻擊效果。吸血不能從被擋或溢出傷害獲利。

凝心修習丹性能力後，每連答至少三題才可再凝聚護體，避免連答門檻後每題護體；雷霆金丹觸發後，額外提供普通實際承傷的 75% 反擊傷害，與法寶和元嬰雷返反擊相加；不是直接反彈 175%。星辰改為每三次作答結算一次，若第三題答錯仍可依先前答對數釋放獨立普通傷害，不觸發法寶暴擊或連擊。尚未修習與金丹以下鬥法維持原有規則。所有元嬰能力在對手境界為金丹以下時停用。

## 可重現平衡檢查

`tests/soul-talent-balance.test.cjs` 使用完整實際鬥法引擎與伺服器角色快照。九丹兩兩對戰，每組 200 場，分別測九品與一品，合計 14,400 場；角色鬥法快照攻擊力 390、最大生命 2250（包含元嬰加成）、全樹十級、無法寶、答對率 80%、首答機會各半，15 回合上限，確定種子可重播。

| 丹性 | 九品勝率（約） | 一品勝率（約） |
| --- | ---: | ---: |
| 滄海 | 50.81% | 48.19% |
| 太初 | 48.63% | 39.88% |
| 凝心 | 53.19% | 50.06% |
| 破境 | 50.00% | 40.44% |
| 星辰 | 47.25% | 44.75% |
| 無垢 | 41.19% | 40.13% |
| 雷霆 | 58.69% | 92.06% |
| 陰陽 | 49.25% | 43.81% |
| 劍心 | 51.00% | 50.69% |

勝率以同一批固定 SHA-256 作答種子、每一品級 36 種配對各 200 場（每丹對 8 種對手，合計 1600 場）重算。勝率基於完整鬥法引擎，抽樣差異請避免過度解讀。**警示：一品雷霆 92.06% 仍高於原本 35%–65% 的勝率觀察範圍**。此次已修正雷霆為加法共享反擊率 +75 個百分點，星辰星隕元嬰係數 ×1.5。測試保留數值輸出及超標警示，不自動替使用者修改數值。此為固定情境工程檢查，不能代表所有裝備組合、答題速度、部分配點或真人策略。

同場普通扣血 200 點、武器反擊率 16% 時，雷霆金丹觸發提供額外 75%，合計 91%，反擊 182 點；若一品完整元嬰雷返另提供 32%，則合計 123%，反擊 246 點（未達元嬰反擊傷害上限時）。
