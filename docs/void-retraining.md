# 煉虛返璞重修

進入煉虛（累積 428 修為）後，顯示為「煉氣期（煉虛）」並從煉氣重新修行。這段所需修為是第一次到達煉虛所需的 428 的一半，即 214；累積修為達 642 即完成重修，晉入合體。

| 顯示境界 | 本輪已修 | 累積修為 |
| --- | ---: | ---: |
| 煉氣期（煉虛） | 0 | 428 |
| 築基期（煉虛） | 3 | 431 |
| 金丹期（煉虛） | 14 | 442 |
| 元嬰期（煉虛） | 34 | 462 |
| 化神期（煉虛） | 94 | 522 |
| 合體 | 214 | 642 |

累積修為與原有養成保留，不對玩家文件扣修為或清空金丹、元嬰、神通、裝備。保留原先的大境界資料索引；重修階段由累積修為即時計算，因此重新登入、跨裝置與獎勵重送不會重置重修進度。原有修為扣減會依同一條曲線回退相應進度。

渡劫 1268、半仙 1868 及真仙的榜上仙位條件沿用原設定。合體門檻從 788 改為 642，對應的閉關獎勵、答題靈石、本命契器境界、修行任務與永久生命加成都同步至 642。重修內的小階段不重複增加境界生命；已取得的境界解鎖與永久生命仍由最高達成境界保留。

`public/cultivation/void-retraining-rules.js` 是無副作用的共用投影：提供重修階段、顯示境界、下一境、當段與全程進度、動畫游標。首頁、即時同步、主流程境界名稱、玩家公開卡與突破提示共用此投影。修為吸收動畫先填滿原階段，再帶入下一階段；相同大境界索引中的重修突破也會觸發提示。登入既有存檔時只顯示目前階段，不重播過去突破。

破境／雷霆金丹在問道、鬥法與團本的瓶頸判定一併加入 431、442、462、522、642，避免顯示與技能實際生效區間不一致。
