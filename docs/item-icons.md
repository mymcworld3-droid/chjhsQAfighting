# 物品圖示與升級石

內建 imagegen 分別生成 23 張透明背景物品圖，統一仙俠手繪風格，保留清楚的縮圖輪廓。最終圖片在 `public/assets/items/`，每張 256×256 WebP；23 張總計不到 0.5 MB。沒有改用向量圖或文字替代生成圖片。

完整生成方式、共用指令、逐項指令及原始檔名見 [item-art-prompts.json](item-art-prompts.json)。以 ImageMagick 等比例縮小、去除中繼資料並轉成 WebP，保留 alpha 透明度。

新增範圍包含靈石、團本入場券、本命法器抽獎券、煉器碎片、元嬰碎精、回魂聚靈丹、修為、八種木鐵素材、二階與三階升級石、五種舊版法寶，以及未知道具的通用儲物袋。本命法器八種器型及太虛劍沿用已有的生成圖片。

`public/cultivation/item-icons.js` 統一圖示與資源別名。背包格子和詳情、煉器素材與升級石、契器餘額與碎片揭曉、團本券與戰利品、元嬰碎精、閉關／任務獎勵、分解和市集共用圖示；保留名稱、數量、品質色框、操作及已有的合法自訂圖片。未知道具顯示儲物袋，不產生動態檔名或執行圖片網址中的程式碼。

| 固定物品 ID | 顯示名稱 | 用途 |
| --- | --- | --- |
| raid-refine-key-ii | 二階升級石 | 第二次煉製，仍不佔八方素材格 |
| raid-refine-key-iii | 三階升級石 | 第三次煉製，仍不佔八方素材格 |

只更改名稱與圖像；物品 ID、持有數量、材料花費、獎勵數量及綁定交易規則沿用原值，不需要搬移庫存。

驗證涵蓋完整內建目錄的圖片連結、檔案格式與體積、資源別名、網址與 HTML 跳脫，以及靈田的管理員／一般玩家讀寫限制。另以本地瀏覽器檢查背包詳情、獎勵圖片與權限切換；不使用正式玩家資料。
