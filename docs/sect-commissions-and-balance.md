# 今日宗門委託（2026-10-16）

每日臺灣時間 00:00 首次打開任務時，由伺服器為每位玩家派發 **2 項額外委託**。原本 6 項日常、37 項仙道任務完全保留。這是額外可選的小獎勵，不要求每天完成所有模式。

- 第一項：「今日誦經」問道答對 4／6／8 題之一，按玩家 UID 與日期決定。
- 第二項：從閉關、洞天、符合境界的鬥法／秘境或有弱項證據時的「弱項研修」中選一。
- 「弱項研修」必須由伺服器驗證 `enlightenmentTrialStates/{uid}` 當日已完成；不能由用戶回傳答對數。
- 所有委託於首次查詢時固定在 `questStates/{uid}.commissionIds`，與領獎狀態 `commissionClaimed` 同存於 Firebase A；不因本日境界提升、重新整理或重登而改變。
- 每日任務額外靈石 55–120，暫不發放抽獎券或大量修為，避免每天必做產生壓力。
- 領獎 API 沿用 `/api/quests/claim`，`kind: 'commission'`；原子交易驗證 uid、日期、派發清單、完成進度並防止重送重領。
- 日常委託卡顯示於「任務 → 日常」上方，具備進度條、獎勵與紅點。未解鎖之玩法不會被派發。

## 元嬰平衡調整

元嬰碎精分支的實際成長收益折半（**不退還已投入的碎精、不修改分支購買成本、不影響基礎金丹與法器數值**）：

| 滿級分支 | 舊 | 新 |
|---|---:|---:|
| 修為答對額外加成 | +10 | +5 |
| 基礎攻擊 | +70 | +35 |
| 生命上限 | +500 | +250 |
| 額外爆擊／連擊機率（依品級） | +10–15% | +5–7.5% |
| 額外爆擊／連擊傷害 | +30／50 百分點 | +15／25 百分點 |
| 金丹丹性技能傷害、回復、反傷與真傷 | 原數值 | 50% |

其中修為結算必須使用整數：每兩級約增加一點，最終 10 級取得 +5；攻擊採整數四捨五入。元嬰加成先減半再套用法器修為倍率，避免重複扣減。

無垢清心丹在鬥法／團本的道心護體發生率改為「品級 9 為 20%、每提升一品級增加 5 個百分點，**最高 60%**」。前後端共用此規則，觸發時有獨立結界光環（支援減少動態效果偏好）。
