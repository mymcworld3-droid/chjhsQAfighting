# 全站同類內容格式

`public/styles/content-format.css` 在首頁預先載入，集中管理同類內容的字級、圓角、圖片比例與操作尺寸。功能模組保留各自的配色、選取／成功／失敗狀態與場景排版。

| 內容角色 | 統一規則 | 使用位置 |
| --- | --- | --- |
| 商品頭像預覽 | 圓形、無內距、cover 等比例填滿、中心定位，不留上下黑邊 | 坊市、洞府頭像背包、管理商品預覽 |
| 人物頭像 | 圓形裝備框；cover 等比例填滿、中心定位，不留上下黑邊 | 仙府、聊天室、好友、排行榜、五仙榜、鬥法配對、修士資料 |
| 圖片相框 | 118% 高度、維持原比例、中心定位 | 商品預覽、已裝備頭像、五仙榜 |
| 法寶／材料／素材圖片 | contain、中心定位、維持原圖比例 | 背包、裝備欄、煉器、交易市集、管理清單、團本掉落、洞天上傳 |
| 一般操作 | 13px、700 字重、12px 圓角、桌面至少40px／手機至少44px | 任務、坊市、修煉、洞天、閉關、鬥法、團本、管理操作、範圍儲存 |
| 圖示關閉／返回 | 36×36px、12px 圓角 | 修士資料、背包詳情、閉關、鬥法、團本 |
| 分類分頁 | 13px、700 字重、12px 圓角 | 坊市、任務、修煉、交易市集、修習範圍 |
| 文字表單 | 14px、1.5行距、12px 圓角；原有多行高度保留 | 洞府、課程、交易市集、洞天、管理表單 |
| 標題 | 頁面22–28px、區段／彈窗18px、內容卡16px | 各主頁、功能彈窗、任務與洞天等內容卡 |
| 卡片／彈窗 | 內容卡16px、彈窗20px 圓角 | 任務、洞天、物品、管理清單、人物資料 |
| 資訊文字／數字 | 12px 名稱、11px 次要資訊、1.6 行距；數字採等寬數字 | 任務進度、交易者、物品清單、素材與裝備資訊 |
| 題面／選項／解析 | 題面17–23px、選項15–18px、解析14px；完整換行 | 問道、閉關、洞天、鬥法、團本 |

新增同類元件時，使用已有的角色 class，或在此共用樣式補入語意相同的 selector；不要在另一個功能重新定義裁切與一般操作尺寸。`ui-avatar-viewport` 的網格必須撐滿容器，避免頭像再次因 flex/grid 縮小而變形。頭像採 cover，超出圓框的部分會置中裁切；不可加回 contain、內接縮圖或內距，造成上下黑邊。圖片相框使用 `ui-product-frame` 或 `ui-avatar-frame`，保留 contain 完整顯示。背包圖片使用 `ui-content-image` 與 `ui-content-fallback`，失效時顯示文字圖示。

導覽列、立繪、Boss 圖像、法陣、技能樹節點、圖片上的小型移除按鈕，以及全螢幕場景的外框／高度各有獨立用途，保留其必要幾何尺寸，不套一般操作或商品圖片規則。登入與開場動畫保持原有排版。

驗證包含實際渲染函式的10個頭像入口、8類物品圖片、11類操作與5類圖示按鈕；另以實際課程、團本、鬥法結算與洞天管理控制器檢查手機直橫向及桌面。坊市驗證必須包含 `index.html` 的預載樣式，並確認橫、直、方形頭像的實際圖片元素撐滿圓框；只檢查 object-fit 無法發現 height:auto 造成的黑邊。測試使用本機資料替身，沒有登入正式玩家帳號或修改正式玩家資料。
