# 金丹圖片

使用內建 `image_gen` 逐張生成，共九種金丹、每種三張透明圖片。完整生成提示詞與每張檔名見 [golden-core-art-prompts.json](golden-core-art-prompts.json)。

正式資產位於 `public/assets/golden-cores/`，皆為 384 × 384、帶透明通道的 WebP；原圖未經重新繪製，僅縮放及編碼以減少手機下載量。

| 金丹 | 檔名前綴 | 圖像主題 |
| --- | --- | --- |
| 大海無垠丹 | `ocean` | 深藍海潮 |
| 太初回元丹 | `taichu` | 金色元氣 |
| 凝心靜音丹 | `ningxin` | 碧玉靜心 |
| 破境衝仙丹 | `pojing` | 赤金破境 |
| 星辰吞月丹 | `xingchen` | 星河銀月 |
| 無垢清心丹 | `wugou` | 冰玉淨蓮 |
| 萬劫雷霆丹 | `thunder` | 紫電雷霆 |
| 陰陽反轉丹 | `reverse` | 黑白陰陽 |
| 破鋒劍心丹 | `sword` | 銀鋒劍心 |

每個前綴均包含 `-low.webp`（七至九品）、`-mid.webp`（四至六品）、`-high.webp`（一至三品），品級越高，金紋與環繞靈氣越華麗。

主金丹、詳情、元嬰裝配、狀態卡、玩家資料與觸發回饋共用同一個圖片對應模組。洗髓揭曉時只更新候選丹，不改動元嬰裝配丹。啟動時優先預載裝配丹、候選丹，再預載其餘金丹圖片；法寶圖片不再加入啟動或背景預載，法寶目錄資料仍照常讀取。

金丹圖片與原本的光暈、軌道、符文、丹紋、靈霧、粒子及高光共同顯示，保留各品級的動態特效與洗髓本體動畫；原有低渲染場景策略仍保留。
