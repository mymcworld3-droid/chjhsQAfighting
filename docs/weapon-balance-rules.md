# 武器境界與輸出平衡規範

適用：《青雲問道》所有武器與武器招式的新增、數值調整及平衡驗收。
確立日期：2026-11-26。

## 核心規則（必須遵守）

**高境界武器的總傷害倍率與輸出率，必須高於低境界武器。**
在相同角色攻擊力、技能等級、精煉星級及可比較的命中條件下，高境界武器必須具備明確的輸出優勢，而不只是擴大範圍、增加戰術複雜度或改變機制。不得透過提高體力消耗完全抵銷高境界武器的傷害優勢。

- 比較基礎輸出技能、主要輸出技能，以及實際可行的戰鬥循環；不能只比較單次命中的倍率。
- 總倍率指對單一目標一次完整命中的所有傷害段數之和；輸出率主要指總倍率除以該次技能消耗的體力。
- 同類、同定位的輸出技能應依境界遞增；控制、位移、輔助技能可依戰術價值個別定價，但不可使整把高境界武器的常態輸出低於低境界武器。
- 共用招式（流風斬、直拳、遠線破擊等）可依所屬武器境界採不同倍率；不得因共用招式 ID 或實作而抹除境界差距。
- 體修承擔近身風險，輸出率可以略高於同境界劍修；低境界武器仍可保有獨特位移、擊退等戰術價值。
- 低境界滿級滿星武器可勝過未培養的高境界武器；境界比較應控制培養條件一致。
- 武器境界為武器本身階級；招式仍依熟練度解鎖，不新增技能境界門檻。

## 初期設計目標（可經實測調整，非已實裝數值）

以煉氣為 100%，築基約 125%，金丹約 160% 的常態輸出效率為參考；每提升一境約增加 25%～30%。此為目標而非所有技能強制使用同一乘數。

| 境界 | 劍修基礎技能倍率（2 體力） | 體修基礎技能倍率（2 體力） |
| --- | ---: | ---: |
| 煉氣 | 120% | 130% |
| 築基 | 150% | 160% |
| 金丹 | 190% | 200% |

## 驗收與特殊機制

1. 在相同攻擊力、技能等級及精煉星級下，檢查各境界基礎招式及主要輸出招式的單目標總倍率與每體力倍率。
2. 多段技能同時檢查完整命中及典型命中；範圍技能另測多目標，不以所有格數乘倍率充當常態單體輸出。
3. 飛劍應納入首次召喚成本、召劍回擊、移動體力及路徑命中；蓄勢納入施放成本、回合／出手限制、減耗與持續時間；連推納入碰撞與提前停止；劍陣納入實際可抵達中心的劍氣段數。
4. 確認問道試煉、武器副本及適用的其他戰鬥模式在實際戰鬥循環中仍有合理的境界優勢，不出現低耗無限攻擊等失衡。
5. 數值更動時同步技能描述、傷害預覽、伺服器結算與回歸測試。

本文件記錄已確立的設計原則；上表為討論中的初始平衡參考，並非現行戰鬥數值。具體倍率仍待實戰平衡測試與另行實作。
