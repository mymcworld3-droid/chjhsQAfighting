# 共用圖文題整合 V1
基準 b1172167。延續通用二維繪圖引擎，不建立各科專屬模板、不指定比例。API 可選擇任意圖文順序。
## 相容格式
現有 q/correct/wrong/exp 及提示、補給字串維持原形，嵌入 [[QYVISUAL:單行JSON:QYVISUAL]]，避免資料庫、票券、快取、隨機選項與批改 schema 遷移。圖表內用純文字標籤；公式仍在正文用 TeX。圖形選項與資料一起保存、一起打亂。舊題無標記時原樣渲染。
含圖表欄位限題幹 1400、每選項 280、解析 1800 字元；每欄最多4塊，防止舊模式截斷。此長度不影響純文字舊題。規格見 question-visual-prompt.cjs。圖表資料不可信，僅解析 JSON、受限運算與內建繪圖，不執行 API 回傳的程式。
## 整合
共用一般/快速/每日閉關提示詞；主 API 對視覺化新題要求獨立審核（包含非 Gemini 路徑）。洞天批次與修復、教師儲存、問道助手及自適應補給接入。共用 quizMathRichText、formatQuizRichText、QuestionPresentation 與教師預覽/教室作答。無效結構在生成或教師儲存時拒絕；舊資料若已損壞，畫面顯示錯誤提示而非執行內容。
## 尚待驗收
此提交新增 Node 測試；仍需 GitHub CI、實際 API 生成、各模式完整端到端、手機/平板測試，以及檢查所有舊快取/題目回報截斷邊界。語意正確性依獨立審核，不宣稱結構檢查可證明圖形正確。2D 函數取樣不保證所有不連續點自動辨識，需適當分 domain；尚無獨立圖表放大器或 3D。
