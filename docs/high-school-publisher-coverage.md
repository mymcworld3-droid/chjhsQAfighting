# 高中出版社冊次覆蓋盤點

依國教院 115 學年度第 1 學期普通型高中審定本清冊（2026-05-28 更新，第 2–3 頁），盤點遊戲已支援的國文、英文、數學、物理、化學、生物、地球科學、歷史、地理、公民與社會。非全部普通高中科目；不納入已移除的資訊科技。清冊提供冊次與出版社，不是課本章節、題庫或版本年度驗證資料。

執行 `npm run audit:high-school-publishers` 即可輸出實際可選冊次、缺項、額外選修地科章名目次、未完成來源、重複冊次及未附出題限制的細項。以 bookId 去重複跨年級顯示資料，乙版獨立計算。回歸測試檢查最低既有覆蓋數及細項提示，允許日後擴增。

目前盤點目標：國文 25、英文 20、數學 64、歷史 24、地理 18、公民 26、物理 36、化學 36、生物 30、必修地科 6，共 285 出版社冊次。選修地科不在此清冊第 2–3 頁，另外列出，不混入分母。

現有舊年度或未標示年度的出版社課名與對照表只代表冊次有資料，不表示 115 學年版本完整。待取得正式詞表、指定文法、原始檔及更精確細項後另補。三民選修地理不在該清冊，不列缺項。
